# 사용자 문구의 한국어 말투

## Decisions

화면 문구는 당근 SEED의 [라이팅 규칙](https://seed-design.io/foundations/writing)과
[보이스앤톤](https://seed-design.io/foundations/voice-and-tone)을 판정 기준으로
삼는다. flyn에서는 다음을 고정한다.

- 기본 종결은 해요체다. 주의가 필요한 상황·자동 발송·법률 문서만 필요한 무게에
  맞춰 합쇼체를 쓴다.
- 존칭어를 줄이고 한 문장에는 한 내용만 쓴다. 부정문, 이중피동, 시스템 관점,
  축약어·은어·유행어를 피한다.
- 버튼과 메뉴 action은 동사형, 입력 필드 label은 명사형으로 쓴다. `다음`, `확인`
  대신 실행 결과를 드러낸다.
- 오류는 사과보다 사용자가 지금 할 수 있는 해결책과 고칠 방법을 우선한다.
- 타이틀·큰 제목·버튼·메뉴·label에는 마침표를 붙이지 않는다.
- 사용자를 부를 때는 `{닉네임}님`을 쓴다. `당신`과 당근 고유 세계관인 `이웃`은
  쓰지 않는다.
- 수는 아라비아 숫자로 쓰고 느낌표는 꼭 필요할 때만 쓴다.

## Why

출시 문자열만 귀납하면 의도와 우연을 구분할 수 없고 세션마다 말투가 달라진다.
SEED는 버튼·필드·오류처럼 반복해서 갈리는 지점을 공개된 판정 규칙으로 제공한다.

## Boundaries

SEED의 지역 커뮤니티 세계관이나 컴포넌트 시각 자산은 가져오지 않는다. 공개
규칙에서 답을 찾지 못한 alert·법률 문구는 문맥과 위험도에 맞춰 별도로 검토한다.

## Reconsider when

flyn의 고유 브랜드 보이스가 정의되거나 SEED 공개 규칙이 현재 제품에 맞지 않게
바뀌면 이 계약을 다시 정한다.

## Still-rejected alternatives

- 적은 출시 문자열만 보고 자체 말투를 추론하기.
- 판정 기준 없이 직접 라이팅 가이드를 만들거나 말투를 세션마다 맡기기.
- 당근의 `이웃` 같은 제품 고유 용어까지 복사하기.

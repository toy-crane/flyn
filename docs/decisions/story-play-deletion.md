# 회차 삭제와 학습 기록 보존

## 결정

- 사용자는 자기 회차 하나를 삭제한다. 해당 회차의 모든 화에서 나눈 대화와 결말,
  회차의 진행과 이야기 기억을 함께 지운다. 다른 회차와 스토리 콘텐츠는 지우지 않는다.
- 메뉴 문구는 `삭제`다. 실행 전에 해당 회차의 모든 화에서 나눈 대화와 결말이
  사라지고 되돌릴 수 없음을 확인한다. 취소하면 아무것도 지우지 않는다.
- 회차를 삭제해도 연속 기록과 영어로 말한 횟수는 유지한다. 완료한 날과 날짜별
  영어로 말한 횟수도 삭제 때문에 줄이지 않는다. 화면을 다시 열거나 나중에 기록을
  다시 계산해도 같은 보존 규칙을 적용한다.
- 학습 기록을 보존한다는 이유로 삭제한 회차의 대화 본문이나 결말을 다시 보여 주거나
  이어갈 수 있게 두지 않는다. 새 대화는 새 회차로 시작한다.
- 노트에 저장한 표현은 [표현 저장 구조](expression-storage.md)의 원본 삭제 규칙을
  따른다. 원본 회차를 지워도 담아 둔 표현은 노트에서 계속 볼 수 있다.

## 경계

- 이 결정은 회차 삭제에 적용한다. 계정 삭제의 보존 범위를 넓히지 않는다.
- 스토리 콘텐츠 삭제, 개별 메시지 삭제, 특정 화만 삭제하거나 되돌리는 기능은 정하지 않는다.
- 학습 기록을 세는 기존 기준은 바꾸지 않는다. 완료하지 않은 화를 완료한 것으로
  세거나, 삭제를 새로운 학습으로 더하지 않는다.
- 학습 기록을 보존할 저장 방식은 이 계약이 정하지 않는다.

## 이유

대화 기록을 정리해도 이미 영어로 말하고 화를 끝낸 사실은 사라지지 않는다.
삭제 때문에 지난 학습 기록이 줄어들면 사용자는 기록을 정리하는 데 불이익을 받는다.
회차의 이야기와 학습한 사실의 수명을 분리해 이 문제를 막는다.

## 재검토 조건

- 사용자가 대화 삭제와 별도로 학습 기록 자체를 초기화할 필요가 생길 때
- 학습 기록을 세는 기준이나 계정 삭제 정책이 바뀔 때

## 계속 제외하는 대안

- 남아 있는 회차만으로 지난 학습 기록을 다시 세기: 삭제가 연속 기록과 영어로 말한
  횟수를 줄인다. 학습 기록 초기화가 별도 행동으로 정의될 때만 다시 검토한다.
- 학습 기록을 지키려고 삭제한 대화를 계속 열어 두기: 대화를 지운다는 약속과 충돌한다.

## 보존할 근거

- 2026-09-14 대화 기록 삭제 검토에서 사용자는 삭제 뒤에도 연속 기록과 영어로 말한
  횟수를 유지해야 한다고 명시했다.

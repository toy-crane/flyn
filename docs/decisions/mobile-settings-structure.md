# 모바일 설정 구조

## 결정

- Settings 첫 화면은 프로필 머리말 뒤에 `계정`, `환경 설정`, `앱 정보`, 제목 없는
  계정 삭제 섹션을 이 순서로 둔다.
- `계정`은 `프로필`, `로그아웃`을, `환경 설정`은 `알림`, `햅틱 반응`, `화면 모드`를,
  `앱 정보`는 `버전`을 담는다. 계정 삭제는 화면 맨 아래 제목 없는 단독 섹션에 둔다.
- 각 설정 항목은 한 개의 행과 한 개의 누르기 영역만 가진다.
- 여러 값 중 하나를 고르는 설정 행은 항목 이름과 현재 값을 보여 주고, 같은 이름의
  전용 하위 화면을 연다. 선택 화면은 모든 값을 나열하고 현재 값 하나에만 선택 표시를
  둔다. 고르면 즉시 적용하지만 화면은 자동으로 닫지 않는다.
- 선택 표시는 iOS에서 체크, Android에서 라디오 버튼을 사용한다. 보이는 표시와 화면
  읽기 상태가 같은 값을 선택됨으로 전달한다.
- 행 오른쪽은 결과의 종류를 나타낸다. 앱 안의 하위 화면 이동은 iOS에서 쉐브론을
  사용하고 Android에는 복사하지 않는다. 외부 이동은 외부 이동 글리프, 즉시 실행과
  확인창은 표시 없음, 스위치는 스위치, 읽기 전용 값은 값만 사용한다.
- 현재 값을 보여 주는 이동 행은 iOS에서 값과 쉐브론을, Android에서 값을 보여 준다.
  작업이 진행되는 동안에는 원래 이름을 유지하고 진행 표시가 오른쪽 자리를 사용할 수
  있다.

## 경계

- Settings의 push 표시와 뒤로 가기는 [모바일 UI 렌더러 경계](mobile-ui-renderer-boundaries.md)가
  소유한다.
- 화면 모드의 값, 기본값과 저장 범위는 [모바일 색상 시맨틱](mobile-color-semantics.md)이
  소유한다.
- 프로필 머리말과 프로필 편집은 [모바일 설정 공개 프로필](mobile-profile-settings.md)이
  소유한다.
- 계정 삭제의 표시, 확인과 실행 결과는 [모바일 계정 삭제](mobile-account-deletion.md)가
  소유한다. 로그아웃과 계정 삭제의 진행 표시는 [모바일 작업 진행 표시](mobile-action-progress.md)를
  따른다.
- 여러 입력값을 초안으로 모아 저장하는 화면은 [모바일 설정 폼 저장](mobile-settings-form-save.md)을
  따른다. 이 계약의 선택 행은 누르는 순간 적용하므로 별도 저장 동작을 두지 않는다.
- 현재 화면에는 외부 이동 행이 없다. 외부 이동 글리프 규칙은 그런 행을 추가할 때
  적용한다.

## 이유

설정을 대상별로 묶으면 계정 동작, 자주 바꾸는 환경 값과 읽기 전용 정보를 서로 다른
자리에서 찾을 수 있다. 여러 선택지를 별도 화면에 모두 보여 주면 현재 값과 가능한 값을
메뉴를 열기 전에도 예측할 필요가 없다.

오른쪽 표시를 누를 수 있다는 장식이 아니라 결과의 의미로 쓰면 내부 이동, 외부 이동과
즉시 실행을 누르기 전에 구분할 수 있다. 플랫폼마다 설정 목록의 표현은 달라도 같은
정보 순서와 결과를 유지할 수 있다.

## 재검토 조건

- Settings 항목이 늘어 현재 네 그룹으로 찾기 어려워질 때
- 선택지가 검색, 여러 구획 또는 설명 화면을 함께 요구할 만큼 많아질 때
- Android의 표준 설정 목록이 내부 이동 표시에 쉐브론을 쓰도록 바뀔 때
- 운영체제가 외부 이동을 알리는 표준 표현을 바꿀 때

## 계속 제외하는 대안

- 여러 값 중 하나를 메뉴나 드롭다운에서 선택: 가능한 값과 현재 선택을 한 화면에서
  비교할 수 없다. 선택지가 한 화면을 감당하지 못할 만큼 늘 때 다시 검토한다.
- 값을 고르면 자동으로 Settings로 돌아가기: 여러 값을 비교하거나 방금 바뀐 화면
  모드를 확인할 기회를 없앤다. 한 번 선택하면 더 볼 내용이 없는 흐름이 생길 때 다시
  검토한다.
- 누를 수 있는 모든 행에 쉐브론 붙이기: 내부 이동과 즉시 실행을 구분할 표시가
  사라진다. 운영체제의 설정 표현이 같은 의미로 바뀔 때 다시 검토한다.
- iOS 설정 행의 모양과 쉐브론을 Android에 복사: Android의 Material 설정 표현과
  어긋난다. 두 플랫폼이 같은 설정 목록 표현을 제공할 때 다시 검토한다.

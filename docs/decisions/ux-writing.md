# UX 라이팅 원칙

플린의 한국어 고정 UI 문구를 쓸 때 따른다.

## 큰 방향

**바로 이해할 수 있게 쓴다.**
익숙하고 구체적인 말로 핵심부터 전한다. 같은 뜻은 같은 말로 쓴다.

**다음 행동에 필요한 만큼만 쓴다.**
사용자가 지금 무엇을 알고, 선택하고, 해야 하는지 생각한다. 화면에서 이미 알 수 있는
설명은 덜어낸다.

**편안하고 담백하게 말한다.**
기본은 해요체로 쓴다. 과한 존칭, 감탄, 사과를 피하고 사용자를 탓하지 않는다.
주의가 필요한 상황에서는 결과를 분명하게 알린다.

## 문장 부호

한 문장짜리 문구에는 마침표를 붙이지 않는다. 두 문장 이상 이어지는 글에는 마지막
문장까지 붙인다. 물음표와 느낌표는 필요할 때 쓴다. 한 문장이 여러 줄로 보여도 문장
수는 달라지지 않으며, 따로 읽는 문구끼리는 합쳐 세지 않는다.

## 적용 범위

- 자동 발송 메시지와 사용자가 조심해야 하는 상황은 기존처럼 합쇼체를 쓴다.
- 제공자가 정한 문구는 해당 제공자의 규칙을 따른다. 사용자 글, 영어 학습 콘텐츠와
  서버가 만든 콘텐츠는 이 원칙으로 고쳐 표시하지 않는다. 법률 문구는 따로 판단한다.
- 채팅 답변과 문서의 글쓰기는 `AGENTS.md`를 따른다.

## 결정 이유와 재검토

세부 규칙을 외우기보다 사용자의 상황에 맞춰 판단할 수 있도록 큰 방향을 둔다.
짧은 문구는 가볍게 끝내고, 이어지는 글은 문장 사이와 끝을 분명히 한다.
외부 디자인 시스템의 글쓰기 기준을 필수로 참조하지 않는다.

이 원칙으로 필요한 설명이 빠지거나 같은 상황에서 판단이 반복해서 갈리면 재검토한다.
지원 언어와 제품의 말투가 바뀔 때도 적용 범위를 다시 정한다.

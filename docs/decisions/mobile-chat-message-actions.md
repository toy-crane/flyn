# 모바일 채팅 메시지 동작

## 결정

- 완료된 AI 답변 아래에는 `답변 복사`와 `답변 다시 받기` 아이콘 줄을 둔다. 답변을
  기다리거나 받는 동안에는 버튼을 보여 주지 않는다. 본문이 나타난 때부터 동작 줄의
  공간을 확보하고, 완료하면 그 자리에 버튼만 표시한다. 숨은 버튼은 누르거나 화면
  읽기 기능으로 선택할 수 없다. 메시지 동작이 없는 화면에는 이 빈 공간도 두지 않는다.
- 답변 복사는 서버에서 받은 Markdown 원문 전체를 클립보드에 넣는다. 다시 받기는
  해당 답변과 그 뒤의 메시지를 버리고 같은 자리에서 답변을 다시 만든다. 별도 확인은
  받지 않는다.
- 사용자 메시지를 길게 누르면 `복사`와 `수정` 메뉴를 연다. 한 번 누르는 것은 아무
  일도 하지 않으며, 사용자 메시지 본문 선택은 끈다.
- 수정은 원문을 입력창에 넣고 해당 메시지부터 뒤의 메시지를 흐리게 보여 준다. 수정해
  보내면 그 메시지부터 대화를 다시 시작한다. `수정 그만두기`를 누르면 대화와 수정 전
  초안을 복원한다.
- 답변을 기다리거나 받는 동안 전송 버튼 자리는 `답변 그만 받기`로 바뀐다. 중지하면
  받은 데까지 답변으로 남기고 별도 중지 표시는 붙이지 않는다.
- 새 질문, 답변 다시 받기와 오류 재시도는 모두 입력창의 같은 중지 버튼을 쓴다.
  요청을 시작한 메시지나 오류 옆에 별도 중지 버튼을 두지 않는다.
- 요청이 실패하면 기존 메시지를 남기고 오류 옆의 `다시 시도하기`로 같은 질문을 다시
  보낸다.
- 사용자 메시지와 AI 답변은 같은 본문 역할을 쓴다. 답변 동작 버튼은 16px 아이콘을
  담은 28px 버튼이고, 그림과 그림 사이는 8pt다. 버튼끼리 붙이면 12pt가 되므로
  좌우로 2pt씩 겹친다. 겹치는 4pt 띠에서는 나중에 그려진 오른쪽 버튼이 손가락을
  받는다. 위아래 누르기 범위만 `hitSlop`으로 6px씩 넓혀 세로 40pt가 된다.
- 누르는 동안 버튼 뒤에 배경을 그리지 않는다. iOS의 하이라이트 원과 Android의
  물결을 둘 다 뺀다. 살짝 작아지는 동작만 남는다.
- 눌렀다는 답은 아이콘 자신이 한다. 복사는 1.5초 동안 체크로 바뀌었다가 돌아오고,
  책갈피는 채워지거나 비고, 다시 받기는 진행 표시로 바뀐다. 아이콘이 바뀌어도 줄은
  움직이지 않는다.
- 아이콘 줄의 버튼을 누르는 순간 가벼운 햅틱을 한 번 준다. 햅틱을 지원하지 않는
  기기에서도 나머지 동작은 같다. 책갈피의 햅틱은 누르는 순간의 것 하나뿐이며,
  저장 토스트는 햅틱을 주지 않는다.
- 줄은 그 메시지가 다 도착한 뒤에 나타난다. 흐르는 동안에는 자리만 비워 두고
  아무것도 그리지 않는다. 장면이 끝나면 대사마다 위에서부터 차례로 떠오르고, 이미
  끝난 대화를 열거나 다른 화면에서 돌아왔을 때는 애니메이션 없이 바로 서 있다.
  줄이 나타날 때 말풍선이 밀리지 않는다.
- 에피소드의 인물 말풍선과 배울 표현 아래에는 복사와 책갈피를 담은 아이콘 줄이
  선다. 이 줄은 대사 하나, 표현 하나에 걸리므로 장면 전체를 다루는 답변 복사,
  다시 받기와는 다른 동작이다. 줄과 버튼의 크기, 간격과 터치 영역은 답변 아래
  아이콘 줄이 정한 값을 그대로 쓰고, 어느 메시지에 어떤 동작을 담는지는
  [표현 노트](expression-note.md)가 소유한다.

## 경계

- AI 답변 본문은 시스템 텍스트 선택을 유지한다. 사용자 메시지에는 앱의 길게 누르기
  메뉴를 붙인다. `AI에게 물어보기`는 구절 선택이 아니라 배울 표현 카드에서 연다.
  진입과 수명은 [모바일 AI에게 물어보기](mobile-ask-ai.md)를 따른다.
- 답변 평가, AI 답변 수정, 복사 성공 알림, 여러 메시지 선택, 되돌린 대화 보관은 이
  동작에 포함하지 않는다. 여기서 말하는 복사 성공 알림은 토스트처럼 화면에 뜨는
  알림이다. 복사 아이콘이 잠시 체크로 바뀌는 것은 알림이 아니라 버튼의 상태다.
  표현을 담았다고 알리는 문구는 그 알림의 예외가 아니라 다른 일이다. 복사는 붙여
  넣기로 바로 확인되지만 담아 둔 것은 다른 탭에 생겨 그 자리에서 보이지 않는다.
- 이 계약의 복사, 다시 받기와 수정은 `AI에게 물어보기`에 적용한다. 에피소드 화면은
  장면 전체에 걸리는 이 동작을 켜지 않는다. 그 화면의 아이콘 줄은 대사 하나에
  걸리는 별도 동작이며 [표현 노트](expression-note.md)가 소유한다. 교정 카드의 다시 보내기는
  [모바일 대화 중 교정](mobile-episode-correction.md)이 소유한다. 저장된
  에피소드의 대화 수명과 기준 메시지 뒤를 지우는 규칙은
  [AI 에피소드 프로토콜](ai-episode-protocol.md)이 소유한다.
- 메시지 표현, 답변 대기 표시, 입력 영역과 최신 메시지 이동은
  [모바일 AI 채팅 표현](mobile-ai-chat-rendering.md)을 따른다.

## 이유

AI 답변의 자주 쓰는 동작은 항상 보이는 작은 아이콘 줄에 두고, 사용자 메시지의
동작은 길게 누르는 메뉴에 두면 본문을 읽는 흐름을 유지하면서 역할을 구분할 수 있다.
수정, 다시 받기와 다시 시도는 모두 대화를 다시 시작하는 지점만 다르므로 같은 채팅
상태 경계에서 처리한다.

동작 줄의 공간을 미리 확보하면 답변이 끝났다는 이유만으로 본문이나 목록이 움직이지
않는다. 복사와 다시 받기는 플린의 기존 기능이므로, 흔들림을 없애기 위해 지우지 않는다.

## 재검토 조건

- 대화를 저장하거나 되돌린 버전을 갈래로 보관할 때
- 사용자 메시지의 텍스트 선택과 길게 누르기 메뉴를 함께 제공해야 할 때
- 메시지 동작이 많아져 아이콘 줄이나 길게 누르기 메뉴에서 찾기 어려워질 때
- 잘못 누른 다시 받기로 대화를 잃는 문제가 사용자 검증에서 반복될 때

## 계속 제외하는 대안

- 되돌리기 전 확인창: 대화 흐름을 매번 끊는다. 저장된 대화나 복구 요구가 생길 때
  다시 검토한다.
- 사용자 메시지 안에 편집 입력창 두기: 목록과 키보드 경계를 복잡하게 만들고 기존
  입력창의 높이 조절과 전송 검사를 다시 구현해야 한다.
- 복사 성공 알림: 클립보드 동작마다 화면 알림을 더한다. 사용자가 복사 결과를 알기
  어렵다는 문제가 확인될 때 검토한다.

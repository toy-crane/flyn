# 연속 기록과 영어로 말한 횟수

## 결정

### 세는 규칙

- 연속 기록은 기기의 현지 날짜를 기준으로 하루에 한 화 이상을 끝낸 날이 이어진
  날수다. 오늘 아직 화를 끝내지 않았으면 어제까지 이어진 날수를 유지한다. 어제를
  끝으로 하루가 통째로 지나면 다음 날부터 0일이다. 같은 날 여러 화를 끝내거나 같은
  화를 새 회차에서 다시 끝내도 하루로 센다.
- 영어로 말한 횟수는 에피소드 대화에서 사용자가 보낸 영어 메시지 수다. 영어 교정과
  한국어 입력 안내를 나누는 판정을 그대로 쓴다. 한국어 메시지와 `AI에게 물어보기`
  메시지는 세지 않고, 수정해서 다시 보낸 메시지는 한 번으로 센다.
- 영어로 말한 횟수와 연속 기록은 서로 다르다. 영어로 말해도 화를 끝내지 않은 날은
  날짜 칸에 횟수를 표시하지만 연속 기록에는 넣지 않는다.
- 완료한 날과 영어로 말한 사실은 대화 원본과 따로 남긴다. 회차를 삭제하거나 지난
  기록을 다시 계산해도 이미 확정한 사실을 빼거나 중복해서 더하지 않는다. 기존
  사용자의 사실은 남아 있는 대화에서 처음 한 번 채우고, 이미 보존한 사실을 남은
  대화만으로 덮어쓰지 않는다.
- 영어로 말한 횟수의 색 단계는 0번, 1~3번, 4~7번, 8~12번, 13번 이상이다.

### 홈과 연속 기록 화면

- 홈의 큰 제목과 프로필 버튼 아래에 `N일 연속` 한 줄과 이번 주 카드를 둔다.
  기록이 없으면 `0일 연속`이다. 세는 규칙 설명, 최장 기록과 색 범례는 두지 않는다.
- 이번 주 카드는 월요일부터 일요일까지 7일을 보여 준다. 제목은 목요일이 속한 달과
  주차를 써서 `9월 2주차`처럼 표시한다. 오른쪽의 `연속 기록 ›`이 탭 바깥의
  `연속 기록` 화면을 연다.
- 날짜 칸은 그날 영어로 말한 횟수의 단계로 칠한다. 아직 영어로 말하지 않은 오늘은
  회색 점선 테두리만 표시한다. 말한 뒤에는 점선을 없애고 횟수에 맞는 색을 쓴다.
  아직 오지 않은 날은 실선 테두리만 두고 누르지 못하게 한다.
- 날짜 칸을 누르면 칸 아래에 `영어로 6번 말했어요` 또는 `기록 없음`을 띄운다.
  한 번에 하나만 보여 주고 레이아웃을 밀어내지 않는다. 같은 칸이나 다른 곳을 누르면
  닫는다.
- `연속 기록` 화면은 같은 연속 기록 한 줄과 월 달력 카드를 보여 준다. 달력은
  월요일에 시작한다. 다음 달은 이번 달에서, 이전 달은 기록이 있는 가장 이른 달에서
  멈춘다. 기록이 없으면 이번 달만 보여 준다. 아래에는 그달의 `영어로 말한 횟수`와
  합계를 둔다.
- 화를 끝내고 홈으로 돌아오거나 앱이 다시 앞으로 오면 최신 기록을 읽는다.

### 색과 접근성

- 횟수 단계는 파란 강조색과 섞이지 않는 앰버 네 단계로 칠한다. 옅은 단계는 노란
  앰버, 진한 단계는 주황이며 밝기와 채도를 함께 바꾼다. 빈 칸은 둘째 표면색,
  아직 영어로 말하지 않은 오늘의 점선은 보조 글자색을 쓴다.
- 날짜 숫자는 두 화면 모드에서 모두 본문 글자색을 쓰며 가장 진한 칸에서도 대비를
  4.5:1 이상으로 유지한다.
- 날짜 칸의 접근성 이름은 날짜와 영어로 말한 횟수를 함께 읽는다. 오늘과 아직 오지
  않은 날은 그 상태도 읽는다.

## 경계

- 앱은 기록을 보여 주기만 한다. 알림, 얼려 두기, 되살리기, 이정표 보상, 공유 이미지,
  리그와 친구 비교는 만들지 않는다.
- 날짜 칸에서 그날 대화로 이동하지 않는다. 홈의 이번 주 카드 아래 영역은 이 결정이
  정하지 않는다.
- 점수와 틀림 개수는 집계하지 않는다.
- 회차 삭제 뒤 학습 사실의 수명은
  [회차 삭제와 학습 기록 보존](story-play-deletion.md)이 함께 정한다.

## 이유

연속 기록은 사용자를 재촉하는 부채가 아니라 이미 해 온 연습을 비추는 기록이다.
홈의 이번 주는 오늘 했는지를, 별도 월 달력은 꾸준했는지를 보여 준다. 색은 활동량을
빠르게 비교하게 하고 툴팁은 범례 대신 정확한 횟수를 알려 준다.

화 완료와 영어 사용은 다른 행동이다. 둘을 하나로 세면 대화만 한 날의 연습을 숨기거나
한국어로 화를 끝낸 날을 영어 사용으로 잘못 표시한다.

## 재검토 조건

- 실제 메시지 분포에서 색이 늘 옅거나 늘 진하게 보일 때 단계 경계를 조정한다.
- 한 번 말한 날까지 색을 붙이는 것이 너무 쉽게 느껴질 때 하루의 최소 횟수를 다시 정한다.
- 연속 기록이 0이 됐을 때 지난 성취를 찾기 어렵다는 사용이 반복되면 최장 기록을 검토한다.
- 거울형 기록만으로 재방문이 늘지 않고 사용자가 다른 장치를 원할 때 부채형 장치를
  하나씩 검토한다.
- 현지 자정 기준이 시간대 이동에서 실제 기록 오류를 반복해서 만들 때 날짜 경계를
  다시 정한다.

## 보존할 근거

- 2026-09-15 iOS와 Android에서 연속 날수, 끊김, 달 이동, 툴팁, 회차 삭제 뒤 보존,
  기본·큰 글자와 밝은·어두운 화면을 확인했다. 가장 진한 칸의 글자 대비는 밝은 화면
  6.45:1, 어두운 화면 5.60:1이었다.
- 같은 날 Android에서 칸 위 장식이 날짜 버튼을 접근성 트리에서 빼는 문제가 있어
  장식을 버튼 뒤로 옮겼다. 날짜 칸 위에 접근성 요소를 겹쳐 두지 않는다.

# 모바일 AI에게 물어보기

## 결정

- 화면 문구와 접근성 이름은 `AI에게 물어보기`를 쓴다. 에피소드의 배울 표현
  카드에서 연다. 일반 채팅과 구절 선택으로 여는 물어보기는 제공하지 않는다.
- 배울 표현 하나에 대화 하나를 둔다. 같은 카드에서 다시 열면 나눈 말과 쓰던
  초안을 유지한다. 첫 질문 전에는 읽기 전용 출처와 입력창만 보여 준다.
- 출처에는 원래 카드와 같은 제목, 내가 쓴 원문과 고친 문장 또는 제안받은
  영어 문장을 보여 준다. 제목은 [모바일 대화 중 교정](mobile-episode-correction.md)을 따른다.
- 대화를 만드는 순간의 에피소드 대화 스냅샷과 해당 교정을 AI 문맥으로 보낸다.
  부모 스냅샷은 메시지 목록에 표시하지 않으며, 물어보기로 부모 대화를 바꾸지 않는다.
- [AI 에피소드 프로토콜](ai-episode-protocol.md)의 `POST /ai/episode/ask`를 쓴다.
  인증, 모델 라우팅과 UI message 스트리밍의 공통 규칙은 유지한다.
- [모바일 UI 렌더러 경계](mobile-ui-renderer-boundaries.md)에 따라 Expo Router
  Stack의 `pageSheet`로 연다. 제목은 `AI에게 물어보기`이며 원래 대화로 돌아갈 때는
  닫기를 쓴다. 닫기 버튼의 접근성 이름은 `AI에게 물어보기 닫기`다.
- 입력창 포커스 시점은 [모바일 진입 키보드](mobile-keyboard-entry-focus.md)를 따른다.
- 시트를 닫아도 메시지, 초안, 전송 상태와 수정 상태를 유지하고 진행 중인 답변도
  계속 받는다. 에피소드 화면을 나가거나 로그아웃하거나 앱 프로세스가 끝나면 지운다.
- 입력창 위에 물어보기 수와 다시 열기 목록을 두지 않는다. 같은 대화로 돌아가는
  길은 에피소드에 남아 있는 배울 표현 카드다.
- 물어보기는 공통 대화 화면의 메시지 표현, 스크롤, 키보드와 스트리밍을 사용한다.
  [모바일 AI 채팅 표현](mobile-ai-chat-rendering.md),
  [모바일 채팅 스크롤](mobile-chat-scrolling.md),
  [모바일 채팅 메시지 동작](mobile-chat-message-actions.md)을 따른다.
  전송, 중지, 복사, 수정, 다시 받기와 오류 재시도는 유지한다.
- 답변의 말투, 글 모양, 답하는 범위와 그 평가는
  [AI에게 물어보기 답변](ask-ai-answers.md)이 소유한다.

## 경계

- 물어보기는 에피소드 화면의 메모리 수명을 따른다. DB, 기기 저장소, 지난 대화
  조회 API, 앱 재시작 뒤 복구와 기기 간 동기화를 추가하지 않는다.
- 물어보기 안에서 다른 물어보기를 만들거나, 부모 대화와 합치거나, 답변을 부모
  대화로 보내지 않는다. 읽기 전용 부모 스냅샷에는 메시지 동작을 붙이지 않는다.
- AI 답변은 시스템 텍스트 선택을 유지한다. 선택 메뉴에 물어보기를 추가하지 않는다.
- 일반 채팅 전용 `/chat`, `/chat/side`와 `POST /ai/chat`은 제거한다.
  에피소드와 물어보기의 공통 대화 기능은 함께 제거하지 않는다.
- 첨부, 이미지, 음성 입력과 모델 고르기를 추가하지 않는다. Expo Web은 지원하지 않는다.
- 네이티브 Stack이 시트 배경, 모서리, 전환과 닫기 제스처를 소유한다.
  `push`, `formSheet`, BottomSheet와 커스텀 시트 모양으로 바꾸지 않는다.

## 이유

물어보기는 교정을 이해하고 다음 말을 준비하는 대화다. 에피소드의 배울 표현 카드가
질문의 출처와 다시 여는 자리를 함께 제공하므로, 별도의 수 표시와 목록이 필요하지 않다.
일반 채팅을 제거해도 이 흐름은 제품의 영어 드라마 경험에 필요하다.

부모 스냅샷은 고정한 AI 문맥으로만 보내고 출처만 화면에 보여 준다. 읽기 전용 문맥과
수정할 수 있는 질문이 섞이지 않고, 원래 에피소드를 바꾸지 않으면서 질문할 수 있다.
`pageSheet`는 키보드와 긴 대화에 필요한 공간, 독립된 화면 수명과 네이티브 닫기를 제공한다.

## 재검토 조건

- 앱을 다시 시작하거나 다른 기기에서 지난 물어보기를 이어야 할 때
- 스냅샷과 물어보기 메시지가 모델 문맥 한도, 비용이나 전송 크기 문제를 반복해서 만들 때
- 카드만으로 지난 물어보기를 다시 찾기 어렵다고 관찰될 때
- 물어보기를 중첩하거나 부모 대화와 합쳐야 한다는 제품 요구가 생길 때
- `pageSheet`가 필요한 대화 공간이나 플랫폼 동작을 안정적으로 제공하지 못할 때

## 계속 제외하는 대안

- BottomSheet 또는 `formSheet`: 긴 대화 공간과 독립된 화면 수명이 부족하다.
- 부모 대화 전체를 시트에 표시: 읽기 전용 문맥과 수정 가능한 메시지가 섞인다.
- 물어보기 영구 저장: 현재의 화면 수명보다 긴 수명과 동기화 규칙을 새로 만든다.
- 시트에 본 채팅으로 보내는 장치 두기: 교정을 이해하도록 돕는 현재 역할을 넓힌다.

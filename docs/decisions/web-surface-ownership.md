# 웹 표면 소유권

## 결정

- 공개 랜딩과 법적 고지 웹 페이지는 `apps/web`이 소유한다. 모바일 앱은 iOS와
  Android만 지원하고 Expo Web을 제품 표면으로 만들지 않는다.
- `apps/web`은 Astro로 정적 파일을 만든다. 서버 런타임이나 배포 어댑터를 두지
  않는다.
- 공개 경로는 `/`, `/terms`, `/privacy`다. 각각 랜딩, 이용약관, 개인정보
  처리방침이 소유한다. 스토어 제출과 앱 링크가 이 주소를 쓸 수 있으므로 경로를
  안정된 공개 계약으로 다룬다.
- 이용약관과 개인정보 처리방침은 사람이 실제 문안을 확정하기 전까지 자리표시자
  상태로 둔다. 자리표시자를 법적 문서처럼 쓰거나 배포 준비가 끝난 것으로 보지
  않는다.

## 경계

- 호스팅 대상, 도메인과 배포 어댑터는 정하지 않는다.
- 랜딩의 카피, 브랜딩과 디자인은 이 계약이 정하지 않는다.
- Google Play의 웹 계정 삭제 요청 경로는
  [모바일 계정 삭제](mobile-account-deletion.md)의 경계에 남아 있다.
- 웹 개발 서버를 시작하고 멈추는 저장소 작업 규칙은 루트 `AGENTS.md`가 소유한다.

## 이유

랜딩과 법적 고지는 브라우저에서 고유 주소로 열려야 하지만 모바일 제품을 웹에서
실행할 필요는 없다. 별도 정적 앱으로 나누면 모바일의 런타임과 지원 플랫폼을
넓히지 않고 스토어와 앱이 가리킬 안정된 주소를 만들 수 있다.

세 페이지는 서버 상태가 필요 없다. 정적 출력으로 두면 호스팅 대상을 나중에
정해도 페이지 구조를 다시 만들지 않아도 된다.

## 재검토 조건

- 로그인, 계정 삭제 요청처럼 서버 상태가 필요한 공개 웹 기능을 만들 때
- 웹 페이지가 늘어 공통 콘텐츠 관리나 동적 렌더링이 필요할 때
- 호스팅 대상을 정해 배포 어댑터나 도메인 규칙을 기록해야 할 때

## 계속 제외하는 대안

- Expo Web에 랜딩과 법적 고지를 넣기: 모바일 앱의 지원 플랫폼과 빌드 범위를
  공개 문서 세 페이지 때문에 넓힌다.
- 실제 문안처럼 보이는 임시 약관을 쓰기: 사람의 확인 없이 법적 문서로 배포될 수
  있다.

# 01 — 스토리 단위 인물

## Outcome

인물이 스토리에 속하고 화는 그중 누가 나오는지를 가리킨다. 프롬프트는 화에
나오는 인물의 설명, 그 화의 무대 글, 지난 이야기 순으로 조립되고, 화를 여는
응답은 인물마다 이름과 스토리 안 순서를 나른다. 다섯 스토리의 인물 열 명과
스물다섯 화의 무대 글이 새 구조로 옮겨져 있고, 데이터베이스가 화당 넷째 인물과
스토리당 다섯째 인물을 거절한다. 앱은 바꾸지 않으며 지금처럼 플레이된다.

## Blockers

None.

## Acceptance criteria

- [x] 다섯 스토리마다 인물 행이 있고, 각 화는 그 스토리의 인물만 가리킨다. 이름은 한 스토리 안에서 겹치지 않는다.
- [x] 화에 넷째 인물을 붙이거나 스토리에 다섯째 인물을 만들면 데이터베이스가 거절한다. 기존 스물다섯 화는 모두 그대로 들어간다.
- [x] 무대 글에 "등장인물은 ~뿐이다. 새 인물을 만들지 않는다" 문장과 인물 항목이 남아 있지 않다. 그 화에서의 인물 사정은 상황 항목으로 남아 있다.
- [x] 2화 프롬프트가 인물 설명, 무대 글, 지난 이야기 순으로 조립되고, Mia의 설명이 1화 프롬프트의 것과 같다. 등장인물 문장은 화에 나오는 인물 데이터에서 만들어진다.
- [x] 화를 여는 응답에 인물마다 이름과 스토리 안 순서가 실린다. Mia는 어느 화에서나 1이고 Owen은 2다.
- [x] 화자 판정이 인물 데이터의 이름으로 동작해 Mia와 Owen의 줄이 말풍선이 된다.
- [x] 운영에 있는 스토리 5개와 에피소드 25개의 ID와 플레이 기록의 연결이 보존된다.

## Constraints

- 스키마는 [Supabase 스키마 작업 방식](../../../decisions/supabase-schema-workflow.md)을 따른다. 선언형 원본을 고치고 `supabase db diff`로 마이그레이션을 만들며, seed가 인물과 무대 글을 재현하고 되풀이 실행해도 기존 ID를 보존한다. 새 마이그레이션에는 `impact.json`과 기존 데이터 보존 검사를 붙인다.
- 배포는 [검증과 내부 테스트 배포](../../../decisions/continuous-delivery.md)를 따른다. DB가 API보다 먼저 운영에 적용되므로 이전 API가 그대로 읽을 수 있는 변경만 먼저 넣고, 이제 쓰지 않는 열을 지우는 파괴적 정리는 별도 검토와 승인 뒤의 마이그레이션으로 미룬다.
- 인물 설명과 화의 사정은 스펙의 "화가 바뀌어도 같은가" 기준과 Mia의 카페 예시를 따른다. 옮기는 것 외에 프롬프트의 내용을 바꾸지 않는다.
- 커밋 전에 읽기 전용 `supabase-reviewer` 검토를 거친다.
- 앱 코드를 바꾸지 않는다. 응답에 더해진 인물 순서는 앱이 무시해도 동작해야 한다.

## Verification

- Supabase pgTAP 테스트: 다섯 스토리의 인물 행과 소속, 스토리 안 이름 중복 거절, 화당 넷째 인물과 스토리당 다섯째 인물 거절, 스물다섯 화의 무대 글에 "등장인물은"과 "새 인물을 만들지 않는다"가 없음을 확인한다. 기존 DB 테스트 전부 통과.
- 기존 데이터 보존 검사: 이전 스키마의 합성 스토리·에피소드·플레이가 마이그레이션 뒤에도 같은 ID와 연결을 유지한다.
- API 테스트: 1화와 2화의 프롬프트를 고정값으로 비교해 조립 순서와 Mia 설명의 일치를 확인하고, 화를 여는 응답이 인물마다 이름과 순서를 싣는 것을 확인한다. 장면 스트림 테스트가 인물 데이터의 이름으로 화자를 판정한다. 기존 API 테스트 전부 통과.
- 타입 생성과 선언형 스키마의 일치 검사 통과.
- 한 플랫폼에서 2화를 열어 첫 장면이 흐르고 답장이 오는 것을 실제 화면으로 확인한다.

## Review checkpoint

One review pass after this task. 범위는 스키마와 마이그레이션, seed 이전, 프롬프트
조립이다. 위험은 운영 DB 마이그레이션이 스토리와 에피소드의 ID나 플레이 연결을
깨뜨리는 것과, 인물 설명이 빠지거나 겹쳐 프롬프트 내용이 조용히 바뀐 채 02의
각본 다시 쓰기와 플레이 검증이 그 위에 쌓이는 것이다.

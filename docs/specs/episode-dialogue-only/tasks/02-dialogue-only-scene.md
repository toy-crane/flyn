# 02 — 지문 없는 장면

## Outcome

모델은 인물 대사만 쓰고 세상의 사건과 반응을 말로 전한다. 에피소드를 열면 첫
말풍선 위에 장면 서술이 한 번 놓이고 그 아래는 말풍선만 흐른다. 이름표는 굵고
인물마다 다른 색이다. 스물다섯 화의 도입이 장면 서술 세 줄과 대사로 다시 쓰여
있고, 무대 글의 지문 지시는 인물의 말로 전하라는 지시로 바뀌어 있다. 상황 줄,
교정, `AI에게 물어보기`, 결말 카드, `표현 돌아보기`는 그대로다.

## Blockers

01. 이름표 색이 인물의 스토리 안 순서를 받아야 하고, 프롬프트의 대사 규칙이
01의 조립 위에 붙으며, 같은 무대 글을 두 작업이 동시에 고치지 않기 위해서다.

## Acceptance criteria

- [x] 다섯 스토리의 1화를 각각 끝까지 플레이했을 때, 모델이 쓴 장면에 이름 없는 줄이 화면에 나타나지 않는다.
- [x] 에피소드를 열면 첫 말풍선 위에 장면 서술이 한 번 보인다. 세 문장 이하, 한 문장이 한 줄, 첫 줄이 굵은 본문색, 나머지 줄은 한 단계 옅은 색이며, 카드 배경도 세로 줄도 없다. 그 아래에는 말풍선만 이어진다.
- [x] 사용자가 "Can I pay with my phone instead?"처럼 묻기만 하면 다음 장면은 사용자가 폰을 댔다고 쓰지 않고 인물이 방법을 안내하며 차례를 넘긴다. 사용자가 "Okay, done."처럼 했다고 말하면 인물이 결과를 말한다.
- [x] 인물 대사에 별표, 괄호 행동, 자기 행동 서술이 없다.
- [x] 2화 이상에서 첫 응답이 지난 화의 일을 대사나 태도로 드러낸다.
- [x] 두 인물이 나오는 화에서 이름표가 굵고 서로 다른 색이며, 같은 스토리의 다른 화에서도 같은 인물은 같은 색이다. 색은 파랑, 보라, 청록과 구분된다.
- [x] 이름표와 장면 서술이 밝은 화면, 어두운 화면, 큰 시스템 글자에서 잘리지 않고 대비를 유지한다.
- [x] 스물다섯 화의 도입이 모두 장면 서술 뒤에 대사만 오는 형태이고, 무대 글에 "지문으로 전한다"가 남아 있지 않다. 인물 소개와 지난 화의 연결은 첫 대사가 맡는다.
- [x] 모델이 이름 없는 줄을 보내면 지금의 작은 회색 줄로 보인다. 장면 서술의 모양을 주지 않고 감추지도 않는다.
- [x] 끝난 화를 다시 열면 장면 서술과 대사가 같은 모양으로 돌아온다.
- [x] 장면 서술 아래에는 복사와 책갈피 아이콘 줄이 없고, 인물 말풍선 아래의 아이콘 줄과 표현 담기는 이전과 같이 동작한다.
- [x] 상황 줄, 교정, `AI에게 물어보기`, 결말 카드, `표현 돌아보기`가 이전과 같이 동작한다.

## Constraints

- 화면은 스펙 폴더의 [프로토타입](../prototype.html)을 따르되 색값과 간격은 실제 기기로 다시 잰다. 프로토타입의 결말 카드와 인물 말풍선 아래 아이콘 줄은 참고용이며 실제 모양은 현재 구현을 따른다.
- 인물 말풍선 아래에 [표현 노트](../../saved-expressions/spec.md)가 붙인 복사와 책갈피 줄이 있다. 장면 서술과 화자 없는 줄에는 그 줄을 붙이지 않고, 담은 표현이 기억하는 대사 위치를 바꾸지 않는다.
- 팔레트는 네 칸이고 칸마다 밝은 화면과 어두운 화면 색이 한 쌍이다. 1번 코랄, 2번 초록, 3번 황토, 4번 분홍 계열이며 색 이름과 등재는 [모바일 색상 시맨틱](../../../decisions/mobile-color-semantics.md)을 따른다.
- 장면 서술의 말투는 지금 도입의 서술체를 유지한다. 도입은 세 문장 이하, 한 문장은 40자 안팎이다.
- 굵은 첫 줄은 에피소드 도입의 장면 서술에만 준다. 화면 읽기 기능은 장면 서술을 첫 말풍선 앞의 본문으로 읽으며 별도 라벨을 붙이지 않는다.
- 이름 없는 줄을 감추거나 직전 화자에게 붙이지 않는다. 이 처리는 스펙의 미정 사항이다.
- 지난 기록은 옮기지 않는다.
- 새로운 접근성 이름을 더하면 `README.md`의 같은 표도 함께 고친다.

## Verification

- 모바일 jest: 도입 메시지의 첫 서술 조각이 장면 서술 모양으로 그려지고, 인물 이름표가 순서별 색과 굵기를 받으며, 대화 중간의 이름 없는 줄은 기존 회색 줄로 그려지는 것을 확인한다. 기존 모바일 테스트 전부 통과.
- API 테스트: 프롬프트에 대사 전용 규칙과 사용자 행동 규칙이 있고 지문 지시가 없음을 고정값으로 확인한다. 기존 API 테스트 전부 통과.
- 콘텐츠 테스트: 스물다섯 화의 도입이 이름 없는 줄 세 개 이하로 시작한 뒤 이름 있는 줄만 이어지고, 무대 글에 "지문으로 전한다"가 없음을 확인한다.
- iOS와 Android에서 `agent-device`로 다섯 스토리의 1화와 한 스토리의 2화를 실제로 플레이한다. 위 질문과 행동 입력을 그대로 보내 인물의 답을 확인하고, 이름 없는 줄과 자기 행동 서술이 없음을 화면 증거로 남긴다. 밝은 화면, 어두운 화면, 큰 시스템 글자를 촬영한다.
- 끝난 화를 대화 기록에서 다시 열어 장면 서술과 이름표가 같은 모양으로 돌아오는 것을 확인한다.

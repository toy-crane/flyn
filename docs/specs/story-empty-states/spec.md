# 스토리와 대화 기록의 빈 화면

상태: 승인. 사용자가 2026-09-09에 [프로토타입](prototype.html)의 두 화면 구현을 요청했다.

## 결과와 범위

- 스토리 탭의 빈 안내를 본문 중앙에 둔다. 대화 아이콘 아래에 `아직 대화한 스토리가 없어요.`를 보통 굵기의 보조색 본문으로 표시한다. Primary `스토리 둘러보기` 버튼으로 탐색 탭에 이동한다.
- 대화 기록에는 표지, 제목과 소개 아래에 얇은 구분선을 두고 `최근 대화` 소제목을 붙인다. 소제목은 작은 글씨와 중간 굵기의 보조색으로 표시한다.
- 기록이 없으면 소제목 아래 남은 공간 중앙에 대화 아이콘과 `아직 나눈 대화가 없어요.`를 표시한다. 추가 버튼은 두지 않는다. 네이티브 헤더의 `새 대화`가 새 플레이를 시작한다.
- 기록이 있으면 소제목 아래에 기존 회차 카드가 들어간다. 소개와 카드는 함께 스크롤한다.

## 완료 기준

- 두 빈 화면의 안내에 굵은 제목을 쓰지 않고, 헤더와 탭 바를 제외한 본문을 기준으로 중앙에 배치한다.
- `스토리 둘러보기`를 누르면 탐색 탭이 열린다. 다시 스토리 탭으로 돌아와도 빈 안내의 위치가 유지된다.
- 대화 기록의 빈 상태와 기록이 있는 상태 모두 구분선 아래에 `최근 대화`를 표시한다. 불러오는 중이나 오류를 빈 기록으로 표시하지 않는다.
- 카드의 날짜순 정렬, 진행 표시, 펼치기와 접기, 이어서 하기, 완료한 화의 대화 열기가 유지된다.
- iOS 기본 글자 크기와 큰 접근성 글자 크기에서 안내와 버튼이 겹치거나 잘리지 않는다. 밝은 화면과 어두운 화면에서 같은 위계를 유지한다.

## 결정 이유와 가정

- 사용자는 과한 굵기와 어색한 배치를 지적했고 중앙 안내와 Primary 버튼을 선택했다.
- 상단 소개와 하단 대화 목록은 구분선과 소제목을 함께 써서 구별한다.
- 아이콘 대체안은 선택하지 않았다. 기존 공용 대화 아이콘과 크기를 유지한다. 이는 나중에 바꿀 수 있는 기본값이다.
- 프로토타입의 가상 회차는 레이아웃 확인용이다. 실제 데이터나 새로운 기능으로 추가하지 않는다.
- 시안의 브라우저용 폰 프레임 대신 앱의 네이티브 헤더와 탭 바를 유지한다. OS가 정하는 높이와 시스템 글자 크기를 반영한다.

## 제외와 한계

서버, 데이터 저장 규칙, 로그인, 기록 카드의 내용과 동작, 다른 화면의 구성은 바꾸지 않는다. Android 실기기 검증은 이번 iOS 확인 범위에 포함하지 않는다. 미결 제품 결정은 없다.

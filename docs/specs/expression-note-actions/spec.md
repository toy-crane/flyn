# 표현 노트에서 질문하고 원래 대화 보기

## 상태

승인. 표현 강조 프로토타입과 추가 사용자 동작을 확정했다. 사용자는 2026-09-15에 대화 이동, 원본 삭제 시 처리, 노트 복귀, AI 질문의 문맥과 유지 기간, 출처 표시와 긴 내용의 표시 순서를 정했다.

2026-09-15 구현했다. 커밋은 `9652d46`부터 `0e64a26`까지다. iOS `flyn-dev-3`와 Android `flyn_dev_3`에서 관찰 가능한 완료 조건을 모두 확인했다. 확인은 기본 글자와 큰 글자(iOS `accessibility-extra-large`, Android 글자 배율 1.6), 동작 줄이기, 로그아웃과 앱 재시작, 다른 기기 삭제를 흉내 낸 로컬 DB 삭제를 포함한다. 한 번의 자동 코드 리뷰를 마쳤다.

같은 날 사용자는 `대화에서 보기`를 카드 아래 오른쪽 아이콘 줄의 말풍선 아이콘으로 바꾸고 노트 카드의 복사를 뺐다. 이웃 말풍선과 겹치던 강조 테두리는 가장자리 안쪽에 그리기로 했다. 두 변경을 iOS `flyn-slot-4`와 Android `flyn_dev_3`에서 영어 교정, 한국어 안내, 인물 대사로 확인했다.

## 사용자에게 필요한 변화

- 저장한 표현을 다시 입력하지 않고 AI에게 질문한다.
- 저장한 표현이 나온 정확한 대화를 열고 앞뒤 맥락을 확인한다.
- 이동한 화면에서 저장한 표현의 위치를 바로 알아본다.

## 승인한 프로토타입

[저장한 표현 찾기](prototype.html)는 원래 대화로 이동한 뒤의 강조 범위를 정한다.
사용자는 2026-09-14에 B안인 테두리 강조를 승인했다. 인물 대사, 영어 교정,
한국어 안내를 state로 바꿔 볼 수 있다. 시연용 문장은 실제 대화 데이터가 아니다.

### 확정한 동작

- 표현 노트에 `AI에게 물어보기` 진입을 제공한다. 사용자가 이 기능에 동의했다.
- 노트에서 AI에게 질문하면 저장한 표현과 그 표현이 나온 원래 대화를 함께 문맥으로 전달한다. 원래 대화나 원본 메시지가 삭제됐다면 저장한 표현만 전달하며, 원본이 없어도 질문할 수 있다. 사용자가 2026-09-15에 확정했다.
- AI 질문창을 닫았다가 같은 표현에서 다시 열면 앞서 나눈 질문과 답을 유지하고 이어서 질문할 수 있다. 사용자가 2026-09-15에 확정했다.
- 노트에서 연 질문창 맨 위의 출처는 대화에서 연 질문창과 같은 카드다. 영어 교정과 한국어 안내는 그 제목, 내가 쓴 원문, 고친 문장이나 안내한 영어를 보여 준다. 인물 대사는 `대사 뜻` 제목, 화자, 영어 대사, 뜻을 보여 준다. 스토리 제목 줄은 두지 않는다. 사용자가 2026-09-15에 노트 카드 모양과 스토리 줄을 더한 모양 대신 이 안을 골랐다.
- 노트에서 연 AI 질문과 답은 다른 탭이나 원래 대화 화면에 다녀와도 유지한다. 앱 프로세스가 끝나거나 로그아웃하면 지우며, 앱을 다시 실행한 뒤에는 복원하지 않는다. 앱을 잠시 백그라운드로 보내는 것만으로 지우지 않는다. 사용자가 2026-09-15에 확정했다.
- 원래 대화는 카드 아래 오른쪽 아이콘 줄에서 휴지통 앞에 서는 말풍선 아이콘으로 연다. 접근성 이름은 `대화에서 보기`다. 노트 카드에는 복사를 두지 않는다. 사용자가 2026-09-15에 처음 정한 글자 버튼을 아이콘으로 바꾸고 복사를 뺐다. 출처 줄은 이동 버튼으로 쓰지 않는다.
- 대화가 아직 있는지 확인하는 동안에는 말풍선 자리에 같은 크기의 진행 표시를 두고 다시 눌리지 않는다.
- 카드의 출처는 기존처럼 `스토리 제목 · N화`로 표시한다. 같은 스토리를 여러 번 해도 날짜나 반복 회차 정보를 덧붙이지 않는다. `대화에서 보기`는 해당 표현이 나온 정확한 대화로 연결한다. 사용자가 2026-09-15에 확정했다.
- 원래 대화나 원본 메시지가 삭제된 표현은 노트에 남기고 `대화에서 보기` 버튼만 숨긴다. 비활성 버튼이나 삭제 안내로 바꾸지 않는다. 사용자가 2026-09-15에 확정했다.
- 버튼을 표시한 뒤 원래 대화나 원본 메시지가 삭제되어 이동할 수 없으면 `대화를 찾을 수 없어요`를 잠깐 알린다. 노트에 그대로 머물고 해당 표현의 `대화에서 보기` 버튼을 숨긴다. 사용자가 2026-09-15에 확정했다.
- `대화에서 보기`는 기존 대화 화면을 연다. 진행 중인 대화는 기존 입력창에서 이어서 말할 수 있고, 끝난 대화는 읽기만 한다. 처음 보이는 위치를 저장한 표현에 맞추며, 노트에서 들어왔다는 이유로 별도 읽기 모드나 이어가기 버튼을 두지 않는다. 사용자가 2026-09-15에 확정했다.
- 대화를 보고 뒤로 가면 표현 노트로 돌아온다. 노트의 읽던 목록 위치와 카드 펼침 상태를 유지한다. 사용자가 2026-09-15에 확정했다.
- 원래 대화에 도착하면 저장한 영어가 있는 말풍선이나 카드의 둘레를 잠깐 강조한다.
- 인물 대사는 해당 대사 말풍선을 강조한다.
- 사용자 영어를 고친 표현은 사용자 메시지 아래 교정 카드를 강조한다.
- 사용자 한국어를 영어로 안내한 표현은 사용자 메시지 아래 영어 안내 카드를 강조한다.
- 사용자 표현은 원문과 교정·안내 카드가 한 화면에 들어가면 함께 보여 준다. 둘이 한 화면보다 길면 저장한 영어 표현을 먼저 보여 주고, 위로 스크롤하면 원문을 읽을 수 있다. 원문 말풍선에는 강조 테두리를 두지 않는다. 사용자가 2026-09-15에 긴 내용의 표시 순서를 확정했다.
- 기존 교정과 안내의 형광펜 색은 유지한다. 배경 강조와 별도의 위치 안내 문구는 사용하지 않는다.
- 강조가 나타나거나 사라질 때 말풍선·카드의 크기와 주변 배치가 바뀌지 않는다.
- 테두리는 말풍선·카드의 가장자리 안쪽에 같은 모서리로 그린다. 인물 대사 아래 대사 뜻, 사용자 말풍선 아래 교정 카드처럼 붙어 선 이웃과 겹치지 않는다. 시안의 테두리는 둘레 밖 5px에 서지만, 사용자가 2026-09-15에 이웃과 겹치는 것을 보고 안쪽 테두리를 골랐다.
- 강조가 끝나면 기존 대화 모양으로 돌아간다.

### 조정 가능한 가정

- 에이전트 가정(사용자가 바꿀 수 있음): DB 정리로 합쳐진 [표현 저장 구조](../../decisions/expression-storage.md)를 사용한다. 인물 대사는 원본 메시지와 `dialogue_index`, 교정·안내는 원본 메시지로 위치를 찾는다. 저장된 표현의 ID만으로 대화 위치를 추측하거나 별도의 노트 복사본을 만들지 않는다. 정확한 원래 대화를 연다는 승인 범위는 유지한다.

- 테두리는 파란 강조색 2px이며 약 2초간 유지한 뒤 서서히 사라진다. 시안의 전체 재생 시간은 2.8초다.
- 실제 기기의 동작 줄이기 설정에서는 테두리를 잠깐 유지한 뒤 전환 효과 없이 제거한다.

## 관찰 가능한 완료 조건

- 같은 표현에서 AI에게 질문하고 질문창을 닫았다가 다시 열면 이전 질문과 답이 보이고 후속 질문을 보낼 수 있다.
- 다른 탭이나 원래 대화 화면에 다녀온 뒤 같은 표현의 AI 질문창을 열면 이전 질문과 답이 남아 있다. 로그아웃 후 다시 로그인하거나 앱 프로세스를 종료한 뒤 다시 실행하면 이전 질문과 답은 보이지 않는다.
- 노트에서 연 AI 질문은 저장한 표현과 연결된 원래 대화를 문맥으로 사용한다. 원래 대화나 원본 메시지가 삭제된 표현도 저장한 표현만으로 질문할 수 있다.
- 노트에서 연 질문창의 출처는 영어 교정과 한국어 안내에서 내가 쓴 원문과 고친 문장을, 인물 대사에서 화자, 영어 대사와 뜻을 보여 준다. 대화에서 연 질문창의 출처와 모양이 같다.
- 원본 대화가 있는 표현에서 카드 아래 아이콘 줄의 `대화에서 보기`를 누르면 해당 표현이 나온 대화로 이동한다.
- 노트 카드의 아이콘 줄에는 `대화에서 보기`와 휴지통만 보이고 복사는 없다.
- 원래 대화나 원본 메시지가 삭제된 표현은 노트에서 계속 읽을 수 있고, `대화에서 보기` 버튼은 보이지 않는다.
- 노트를 연 뒤 다른 기기에서 원본 대화나 메시지를 삭제하고 `대화에서 보기`를 누르면 `대화를 찾을 수 없어요`가 잠깐 보인다. 노트와 저장한 표현은 그대로 남고 해당 버튼은 숨겨진다.
- 진행 중인 대화를 노트에서 열면 저장한 표현의 위치에서 읽기를 시작하고 기존 입력창으로 메시지를 보낼 수 있다. 끝난 대화를 열면 기존 읽기 전용 동작을 유지한다.
- 노트의 아래쪽에서 카드를 펼치고 `대화에서 보기`로 이동한 뒤 돌아오면, 같은 목록 위치에서 해당 카드가 펼쳐진 상태로 보인다.
- 세 출처에서 각각 저장한 영어가 있는 대상만 테두리로 강조된다. 테두리는 바로 위아래에 붙은 말풍선이나 카드에 겹치지 않는다.
- 원문과 교정·안내 카드가 짧으면 한 화면에서 함께 보인다. 둘이 한 화면보다 길면 저장한 영어 표현이 먼저 보이고 위로 스크롤해 원문을 읽을 수 있다.
- 같은 스토리를 반복한 기록도 저장한 표현이 나온 정확한 대화로 연결된다.
- 같은 스토리를 여러 번 한 경우에도 카드 출처는 `스토리 제목 · N화`로 보이며 날짜나 반복 회차 정보는 표시하지 않는다.
- 기본 자동 스크롤이 목표 표현 위치를 곧바로 벗어나게 하지 않는다.
- 테두리가 사라져도 읽던 위치와 기존 문장의 색은 유지된다.

## 남은 검증

- 큰 글자에서 저장한 영어 표현이 먼저 보이고 위로 스크롤해 원문을 읽는 것은 두 시뮬레이터로 확인했다. 물리 기기와 작은 화면 기종에서는 아직 확인하지 않았다.
- 목록의 첫 배치가 1초보다 오래 걸리는 느린 기기에서 자리 잡기가 목록 자체의 첫 스크롤보다 먼저 실행되는지는 확인하지 않았다. 코드 리뷰가 가능성으로 짚었고 시뮬레이터에서는 재현되지 않았다.

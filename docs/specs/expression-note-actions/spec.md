# 표현 노트에서 질문하고 원래 대화 보기

## 상태

표현 강조 프로토타입은 승인했다. 기능 전체의 구현 계약은 아래 미정 사항을 정한 뒤 마친다.

## 사용자에게 필요한 변화

- 저장한 표현을 다시 입력하지 않고 AI에게 질문한다.
- 저장한 표현이 나온 정확한 대화를 열고 앞뒤 맥락을 확인한다.
- 이동한 화면에서 저장한 표현의 위치를 바로 알아본다.

## 승인한 프로토타입

[저장한 표현 찾기](prototype.html)는 원래 대화로 이동한 뒤의 강조 범위를 정한다.
사용자는 2026-09-14에 B안인 테두리 강조를 승인했다. 인물 대사, 영어 교정,
한국어 안내를 state로 바꿔 볼 수 있다. 시연용 문장은 실제 대화 데이터가 아니다.

### 확정한 동작

- 표현 노트에 `AI에게 물어보기` 진입을 제공한다. 사용자가 이 기능에 동의했다.
- 원래 대화는 카드 아래의 별도 글자 버튼 `대화에서 보기`로 연다. 사용자가 2026-09-15에 버튼의 자리와 문구를 확정했다. 출처 줄은 이동 버튼으로 쓰지 않는다.
- 원래 대화에 도착하면 저장한 영어가 있는 말풍선이나 카드의 둘레를 잠깐 강조한다.
- 인물 대사는 해당 대사 말풍선을 강조한다.
- 사용자 영어를 고친 표현은 사용자 메시지 아래 교정 카드를 강조한다.
- 사용자 한국어를 영어로 안내한 표현은 사용자 메시지 아래 영어 안내 카드를 강조한다.
- 사용자 표현은 원문과 교정·안내 카드를 함께 볼 수 있도록 이동한다. 원문 말풍선에는 강조 테두리를 두지 않는다.
- 기존 교정과 안내의 형광펜 색은 유지한다. 배경 강조와 별도의 위치 안내 문구는 사용하지 않는다.
- 강조가 나타나거나 사라질 때 말풍선·카드의 크기와 주변 배치가 바뀌지 않는다.
- 강조가 끝나면 기존 대화 모양으로 돌아간다.

### 조정 가능한 가정

- 에이전트 가정(사용자가 바꿀 수 있음): DB 정리로 합쳐진 [표현 저장 구조](../../decisions/expression-storage.md)를 사용한다. 인물 대사는 원본 메시지와 `dialogue_index`, 교정·안내는 원본 메시지로 위치를 찾는다. 저장된 표현의 ID만으로 대화 위치를 추측하거나 별도의 노트 복사본을 만들지 않는다. 정확한 원래 대화를 연다는 승인 범위는 유지한다. 원본 없는 표현의 이동 입구와 AI 질문 수명은 아래 미정 사항으로 남긴다.

- 테두리는 파란 강조색 2px이며 약 2초간 유지한 뒤 서서히 사라진다. 시안의 전체 재생 시간은 2.8초다.
- 실제 기기의 동작 줄이기 설정에서는 테두리를 잠깐 유지한 뒤 전환 효과 없이 제거한다.
- 원문과 카드가 한 화면보다 길면 저장한 영어를 먼저 보여 준다. 긴 원문의 최종 배치는 추가 확인한다.

## 관찰 가능한 완료 조건

- 원본 대화가 있는 표현에서 카드 아래의 `대화에서 보기`를 누르면 해당 표현이 나온 대화로 이동한다.
- 세 출처에서 각각 저장한 영어가 있는 대상만 테두리로 강조된다.
- 같은 스토리를 반복한 기록도 저장한 표현이 나온 정확한 대화로 연결된다.
- 기본 자동 스크롤이 목표 표현 위치를 곧바로 벗어나게 하지 않는다.
- 테두리가 사라져도 읽던 위치와 기존 문장의 색은 유지된다.

## 필요한 기존 결정

- [표현 노트](../../decisions/expression-note.md): 저장 대상과 노트 카드의 기존 역할을 정한다.
- [모바일 AI에게 물어보기](../../decisions/mobile-ask-ai.md): 기존 질문 시트와 문맥을 정한다. 노트 진입의 수명은 아직 미정이다.
- [모바일 탭과 상세 화면 배치](../../decisions/mobile-tab-navigation.md): 대화 상세의 탭 표시와 복귀 원칙을 정한다.
- [모바일 채팅 스크롤](../../decisions/mobile-chat-scrolling.md): 기존 자동 스크롤과 읽던 위치의 동작을 정한다.
- [UX 라이팅 원칙](../../decisions/ux-writing.md): 앱 문구를 정한다.

## 미정 사항과 위험

- 출처 줄의 화 번호와 반복 플레이 정보 표시는 제안 단계다.
- 원본 메시지가 삭제된 경우 이동 버튼을 숨기는 안은 제안 단계다. 존재 여부가 이동 직전에 바뀌는 경우의 안내도 정해야 한다.
- 진행 중인 대화에 들어갈 때 읽기만 할지 이어서 말할 수 있을지 아직 정하지 않았다.
- 노트로 돌아올 때 목록 위치를 유지하는 방향을 제안했으나 최종 복귀 동작은 구현 전에 확인한다.
- 노트에서 연 AI 질문의 문맥, 다시 열기와 보관 수명은 아직 정하지 않았다.

## 범위 밖

이 승인만으로 새 검색·필터, 복습 퀴즈, AI 질문 영구 보관을 추가하지 않는다.
빈 상태의 중앙 배치는 이 PR에 포함한 별도 수정으로 처리했다.

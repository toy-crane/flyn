# 01 — 표현을 담아 두면 대화에 남는다

## Outcome

사용자가 에피소드에서 인물의 대사와 배울 표현을 책갈피로 담고 다시 눌러 취소한다. 담은 것은 계정에 남아서 앱을 다시 켜거나 다른 기기에서 로그인해도 같은 메시지 곁에 책갈피가 채워진 채로 돌아온다. 담는 순간 인물 대사에는 한국어 뜻이 만들어지고, 영어 교정과 한국어 안내는 이미 저장된 이유를 그대로 가져간다.

## Blockers

None.

## Acceptance criteria

- [ ] 인물 말풍선마다 책갈피가 있고, 탭하면 채워지며 토스트와 햅틱이 나온다. 다시 탭하면 비고 토스트는 나오지 않는다.
- [ ] 배울 표현의 접힌 한 줄과 펼친 카드의 제목 줄에 같은 책갈피가 있고 둘이 항상 같은 상태를 보여 준다.
- [ ] 지문과 내 말풍선에는 책갈피가 없다.
- [ ] 인물 대사의 책갈피는 말풍선 오른쪽 옆, 배울 표현 한 줄의 책갈피는 왼쪽 옆에 있고 세로 위치는 말풍선 아래 끝에 맞는다.
- [ ] 한 장면에 인물 대사가 여럿이면 각각 따로 담기고, 표시는 담은 대사에만 붙는다.
- [ ] 인물 대사를 담으면 한국어 뜻이 함께 저장된다. 영어 교정과 한국어 안내는 뜻을 만들지 않고 곧바로 저장된다.
- [ ] 저장이 실패하면 `표현을 저장하지 못했어요.`와 새로고침 아이콘이 한 줄로 뜨고, 그 아이콘이나 책갈피를 누르면 다시 시도한다. 이 줄은 매달린 말풍선이나 한 줄의 정렬을 따른다.
- [ ] 같은 장면의 같은 대사, 같은 메시지의 같은 출처 종류를 두 번 담아도 항목이 하나만 생긴다.
- [ ] 앱을 껐다 켜거나 다른 기기에서 로그인해도 대화를 다시 열었을 때 책갈피 상태가 그대로다.
- [ ] 담은 뒤 그 메시지를 다시 받기나 수정으로 지워도 저장 항목은 남는다.
- [ ] 끝난 화를 읽기 전용으로 다시 열어도 인물 대사를 담을 수 있다. `AI에게 물어보기` 시트 안에서는 담을 수 없다.
- [ ] 접근성 이름이 저장은 `표현 저장`, 취소는 `저장 취소`, 실패의 다시 시도는 `표현 저장 다시 시도`다.
- [ ] [모바일 대화 중 교정](../../../decisions/mobile-episode-correction.md), [모바일 채팅 메시지 동작](../../../decisions/mobile-chat-message-actions.md), [모바일 AI 채팅 표현](../../../decisions/mobile-ai-chat-rendering.md)이 이 작업에서 바뀐 경계를 반영한다.

## Constraints

- 저장 항목의 값과 자리 규칙은 [스펙](../spec.md)을 따른다. 화면 모양은 [프로토타입](../prototype.html)의 에피소드 화면과 같다.
- 데이터를 지키는 규칙은 [쓰기 규칙이 사는 자리](../../../decisions/supabase-write-rules.md)에 따라 데이터베이스가 소유한다.
- 표현 노트 화면과 하단 탭은 이 작업에서 만들지 않는다.

## Verification

- `bun run db:test`가 새 테이블의 정책과 권한을 확인하는 테스트를 포함해 통과한다.
- `bun run test`와 `bun run check`가 통과한다.
- `agent-device` 한 세션에서 담기, 취소, 앱 재시작 뒤 복원, 다시 받기로 메시지를 지운 뒤에도 항목이 남는 것을 순서대로 확인한다.

## Review checkpoint

One review pass after this task. 새로 만든 테이블과 그 정책, 권한, 저장과 취소의 쓰기 경로가 대상이다. 계정에 쌓이는 데이터라 정책이나 권한이 틀리면 다음 작업의 조회가 그 위에 그대로 얹힌다. 이 저장소의 `supabase-reviewer`가 이 범위를 맡는다.

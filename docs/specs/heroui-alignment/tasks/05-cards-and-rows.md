# 05 — 카드와 목록 행 이전

## Outcome

기억해 둘 표현과 표현 노트의 펼침 카드가 HeroUI `Accordion` 표면 변형으로,
인물 대사 카드와 회차 카드가 HeroUI `Card`로, 스토리 행과
스토리 상세·대화 기록의 화 행과 추천 아이디 행이 HeroUI `ListGroup`과
`Separator`로 그려져 같은 모양과 눌림 반응을 갖는다. 표현 카드 아래 오른쪽 아이콘
줄은 접힌 상태에서도 같은 자리에 남는다. 회차 카드 본문은 에피소드 Sheet를 열고
오른쪽 `···`는 별도 메뉴를 연다. 화 열기와 이어서 하기는 Sheet에서 고른다.
표현 카드의 펼침, 복사와 담기는 지금과 같고, 펼친 내용을 눌러 접는 동작만 없어진다.

## Acceptance criteria

- [ ] 여섯 자리(스토리 행, 스토리 상세 화 행, 대화 기록 화 행, 추천 아이디 행, 기억해 둘 표현·표현 노트 카드, 회차 카드)에 원시 `Pressable`이 없고, 그 자리와 대화 기록 헤더 아래에 손으로 그린 구분선이 없다. 저장소의 원시 `Pressable`은 계약의 예외 목록과 일치한다.
- [ ] 표현 카드의 제목 줄을 누르면 펼쳐지고 다시 누르면 접힌다. 아이콘 줄을 눌러도, 카드를 옆으로 12pt 넘게 밀다 떼도 카드가 열리지 않는다.
- [ ] 접힌 표현 카드에도 아이콘 줄이 보인다. 인물 대사 카드는 쉐브론이 없고 눌러도 펼쳐지지 않는다.
- [ ] 회차 카드 본문은 Sheet, 오른쪽 `···`는 메뉴만 연다. 카드 안 펼침, 접기 쉐브론과 카드 밖 이어서 하기 버튼이 없다.
- [ ] 눌리는 행은 축소 반응이 있다. 결과만 남고 대화 원본이 없는 끝난 화와 스토리 상세의 화 행은 눌리지 않는다. Sheet의 현재 화는 대화가 없어도 `시작하기`로 열린다.
- [ ] 접근성 트리에서 펼침 카드는 출처·영어·한국어를 이은 이름과 `expanded` 상태를 가진 버튼으로, 눌리는 행은 제목과 설명을 잇는 이름의 버튼 하나로 읽힌다.
- [ ] 회차 카드 본문과 `···`는 서로 다른 이름의 컨트롤로 읽히고, 본문에 `expanded` 상태가 없다.
- [ ] 동작 줄이기가 켜지면 펼침 애니메이션이 없다.
- [ ] 탐색, 표현 돌아보기, 표현 노트, 스토리 상세, 대화 기록, 온보딩 아이디 화면을 계약의 절차로 기본 크기와 최대 글자 크기, 밝은 화면과 어두운 화면으로 열어 잘림과 겹침이 없고, 큰 글자에서 카드의 쉐브론이 첫 줄에 붙는다.

## Constraints

- 01이 끝난 뒤에 한다. 첫 기준의 "저장소의 원시 `Pressable`이 예외 목록과 일치한다"는 01이 재시도 알약, 편집 취소 버튼, 프로필 편집 알약, 전송·중지·최신 메시지 버튼을 옮겨야 참이 된다. 04 뒤에 하면 카드와 행 안의 글자를 다시 만지지 않지만 필수는 아니다.
- 행의 눌림 반응은 `PressableFeedback`으로 행을 감싸고 `onPress`를 그쪽에 두며 `ListGroup.Item`은 `disabled`로 둔다. 버튼 역할과 이름은 감싼 쪽에 준다.
- 펼침 카드마다 독립 `Accordion`이며 `selectionMode="single"`과 접기 허용을 명시한다. 표현 카드의 아이콘 줄은 내용 슬롯이 아니라 카드 밖 아래에 둔다.
- 회차 카드의 `Card` 본문은 `PressableFeedback`으로 누름을 처리하고, 오른쪽 `···`를 독립된 컨트롤로 둔다. Sheet 표시는 [모바일 UI 렌더러 경계](../../../decisions/mobile-ui-renderer-boundaries.md), 화 선택 동작은 [회차 선택·삭제 명세](../../story-record-deletion/spec.md)를 따른다. 두 작업이 겹치면 먼저 구현한 쪽을 재사용한다. 실제 삭제와 학습 기록 보존은 회차 선택·삭제 명세의 범위다.
- 표현 카드의 접근성 이름은 [표현 노트](../../../decisions/expression-note.md)대로 직접 넘기고, 옆으로 민 판정은 트리거의 누름 속성으로 유지한다. 유지할 수 없으면 그 카드만 되돌리고 그 계약의 보존할 근거에 적는다.
- 펼침 카드 트리거의 첫 줄 맞춤은 global.css의 재정의 하나로 한다. 화면 코드에서 className으로 덮지 않는다.
- 배율 재생성 처치 제거는 [글자 크기 스펙](../../text-size-after-relaunch/spec.md)과 겹친다. 이 task를 시작할 때 남아 있는 것만 없앤다.
- 대화 중 배울 표현의 한 줄과 카드는 계약의 예외라 손대지 않는다. 카드와 행의 내용과 동작은 [표현 노트](../../../decisions/expression-note.md), [에피소드 종료와 표현 돌아보기](../../../decisions/episode-ending-and-review.md), [모바일 스토리 탐색](../../../decisions/mobile-story-browsing.md)이 소유한다.
- 동작 줄이기 처리는 [에피소드 종료와 표현 돌아보기](../../../decisions/episode-ending-and-review.md)의 규칙을 따른다.

## Verification

- 원시 `Pressable` 사용 파일 목록이 [모바일 컴포넌트 선택](../../../decisions/mobile-component-selection.md) 예외 목록의 자리와 같다. 여섯 자리와 대화 기록 헤더에 `border-b`, `border-t`, `h-px`가 0건이다.
- `bun run check`와 모바일 `bun run test`가 통과하고, 카드의 접근성 이름·역할·`expanded` 상태, 행의 접근성 이름, 옆으로 민 판정을 검사하는 테스트가 있다.
- 기기 확인: 계약의 절차대로 최대 글자 크기로 바꾼 뒤 앱을 완전히 닫고 다시 시작해 여섯 화면을 iOS와 Android, 밝은·어두운 모드로 찍는다. 통과 조건은 잘림과 겹침이 없고 쉐브론이 첫 줄에 붙는 것이다.
- `agent-device`로 표현 카드 제목 줄 누르기, 아이콘 줄 누르기, 옆으로 밀기를 실행해 접근성 트리의 `expanded` 값이 기대와 같다. 접힌 표현 카드에서 아이콘 줄이 트리에 있다.
- 회차 카드 본문과 `···`를 각각 눌러 Sheet와 메뉴가 따로 열리는지 확인한다. Sheet에서 대화가 없는 현재 1화 시작, 진행 중인 화 이어서 하기, 끝낸 화 읽기를 확인한다.
- 종료 카드가 있는 대화 화면에서 축하 연출 뒤 카드를 펼쳐 내용이 접근성 트리에 나타난다. 동작 줄이기를 켠 뒤 같은 확인을 반복한다.
- 변경을 `mobile-ui-consistency-reviewer`로 검토한다.

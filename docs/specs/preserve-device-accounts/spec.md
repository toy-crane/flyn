# 기기 계정을 유지하는 개발 기기 풀

## 목적과 범위

개발자가 기기에 로그인한 Apple·Google 계정을 기기 반납 뒤에도 재사용한다. 플린 앱 로그인과 기기 계정 로그인을 구분한다. 로컬 Simulator·Emulator에 적용하며 실기기는 포함하지 않는다.

## 동작과 완료 조건

- 플랫폼별 기존 배정을 우선하고, 빈 기기를 재사용한다. 필요할 때만 최대 5개까지 만든다.
- 모두 배정 중이면 추가 생성 없이 배정 현황과 반납 명령을 안내한다.
- 일반 종료는 기기 배정과 앱 데이터를 유지한다. 명시적 반납과 사라진 worktree 회수는 플린 앱만 삭제하고 기기를 종료한 뒤 풀로 돌려놓는다.
- 기기 식별자, 기기 계정, 기기 설정과 다른 앱은 보존한다. 전체 초기화는 실행하지 않는다.
- 이미 플린 앱이 없으면 반납을 계속한다. 삭제 또는 종료 실패 시 재배정하지 않고 오류를 알린다.
- 다음 작업은 해당 작업과 호환되는 공용 빌드를 설치한다. 호환 빌드가 없을 때만 새로 빌드한다.

## 기본값과 한계

일반 종료 시 배정 유지와 필요할 때 기기 생성은 기존 동작을 유지하는 기본값이다. 5는 플랫폼별 기기 수 제한이며 worktree slot 번호와 다르다. 기존 기기를 교체하거나 미리 5개를 생성하지 않는다.

iOS 앱 삭제는 Keychain 전체 삭제를 뜻하지 않는다. 플린은 세션 본문을 앱의 SQLite에 저장하므로 앱 삭제 뒤 남은 암호화 키만으로 세션을 복원할 수 없다. 계정 제공자의 재인증 요구까지 방지하지는 않는다. 실제 계정 재인증 여부는 이 변경의 보장 범위가 아니다.

## 검증 기록

2026-09-09에 개발 세션 테스트 140개, scripts 타입 검사와 정적 검사를 통과했다. 배정되지 않은 iOS Simulator와 Android Emulator에서 실제 공용 빌드 설치, 앱 삭제, 기기 데이터 확인용 파일 보존, 공용 빌드 재설치를 확인했다. iOS는 삭제 전 앱 컨테이너에 넣은 파일이 재설치 후 사라진 것도 확인했다. 확인용 파일은 제거하고 기기는 종료했다. 실제 Apple·Google 계정의 로그인 지속 여부는 직접 검증하지 않았다.

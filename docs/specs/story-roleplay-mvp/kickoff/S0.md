# S0 — 기반 (단독 실행, 모든 스트림의 선행 세션)

`kickoff/README.md`의 공통 규약을 따른다. 이 세션의 산출물이 이후 모든 세션의
공통 지반이므로, 여기서 정한 이름·계약이 곧 프로젝트 표준이 된다.

## 스코프

1. **의존성 일괄 추가** — 이후 스트림이 쓸 패키지를 이 세션에서 한 번에 추가한다
   (병렬 PR의 lockfile 충돌 방지). 최소: AI SDK(게이트웨이 포함)·zod·
   `@supabase/supabase-js`·auth 저장용 스토리지·`expo-apple-authentication`.
   정확한 목록은 ai-sdk / supabase / expo 스킬을 참조해 판단한다.
2. **앱 설정** — app.json: 이름 `flyn`, 번들 ID `com.toycrane.flyn`,
   `usesAppleSignIn`, 아이콘(`app-icon.svg` 마스터 → 1024 풀블리드 PNG), 스플래시,
   API 라우트용 `web.output: "server"`.
3. **디자인 토큰·폰트** — 프로토타입 `:root`의 토스 토큰을 Tailwind 4 테마로.
   본문은 iOS 시스템 폰트(번들 폰트 없음), 내레이션·북커버·The End 전용
   세리프(`ui-serif`) 처리.
4. **공유 컴포넌트** (`src/components/`) — 프로토타입 CSS에서 추출: 상단 바, CTA
   바, 상황 카드, 칩, 선택지(lvl), 바텀 시트, 북커버, 스탯 타일, inset grouped
   list, 채팅 버블·내레이션, 입력바, 빈 상태 등. 프로토타입과 시각 대조로 검증.
5. **라우트 스켈레톤** — IA 전체: 로그인·온보딩 그룹, NativeTabs 3탭(홈·서재·
   프로필), 몰입 플로우 스택(상황 만들기·세션·결과·교정 스레드), 책 상세 푸시.
   탭 바 노출 규칙(스펙 IA 절) 준수. 각 라우트는 얇은 래퍼,
   `src/screens/<name>/index.tsx`에 픽스처를 표시하는 플레이스홀더.
6. **도메인 타입** (`src/types/`) — 글로서리 용어의 영문 명칭 그대로: LearnerProfile,
   Scenario, StorySession, Ending, Narration/Dialogue/Action, Correction,
   CorrectionThread 등.
7. **데이터 접근 심** (`src/lib/`) — 인터페이스 + 인메모리 목 구현 + 프로토타입
   내용 그대로의 픽스처(Night train to Budapest 등, 상태 변형 포함).
8. **AI 계약 스키마** — 상황 생성 / 스토리 턴 / 교정 스레드 3개 라우트의 요청·응답
   zod 스키마. 스토리 턴 응답에는 내레이션·대사·교정·달성 판정·결말이 표현돼야 한다.

# S6 — 결과 + 서재 + 책 상세 (배치 3, S3과 병렬)

`kickoff/README.md`의 공통 규약을 따른다. 프로토타입 화면: ⑤ 결과(상태 2종),
⑦ 서재(상태 2종), ⑨ 책 상세. 데이터는 **목 심만** 사용 — 실연결은 S7 소관.

## 스코프

1. **결과** (`src/screens/session-result/`) — 방금 완성한 책 표지 히어로(결말
   배지), 세리프 이탤릭 "The End", 스트릭 한 줄, 요약문, 통계 3종(턴/교정/교정
   대화), 교정 리뷰 목록(→ 교정 스레드), 하단 고정 "완료" CTA(→ 홈). "새 이야기
   시작" 버튼 없음(스펙 확정). 교정 없음 상태 포함.
2. **서재 탭** (`src/screens/library/`) — 2열 북커버 그리드(장르색·세리프 제목·
   책등 음영·결말 배지·메타 라인), "완성한 이야기 N", 첫 사용 빈 상태.
3. **책 상세** (`src/screens/book-detail/`) — 미니 표지 + 완성 시점 메타, "대화
   다시 읽기"(세션 화면의 읽기 전용 렌더 — S5의 화면을 재사용하되 S5 폴더를
   수정하지 않는 방식은 계획 시 판단하고, 충돌 소지가 있으면 읽기 전용 뷰를 자기
   폴더에 구현), 그때의 교정 목록(→ 교정 스레드). 탭 바 표시(탭 내 푸시 상세).

# S3 — 온보딩 + 프로필 (배치 3, S6과 병렬)

`kickoff/README.md`의 공통 규약을 따른다. 프로토타입 화면: ① 온보딩(상태 5종),
⑧ 프로필. 데이터는 **목 심만** 사용 — 실연결은 S7 소관.

## 스코프

1. **온보딩 5스텝** (`src/screens/onboarding/`) — 한 화면 한 질문: 수준(3단 자가
   진단) → 목적(복수) → 장르(복수) → 관심사(복수, 12종) → 닉네임(선택, 건너뛰기).
   전부 선택지 기반, 자유 텍스트는 닉네임뿐. 완료 시 심에 프로필 저장 후 홈으로.
2. **프로필 탭** (`src/screens/profile/`) — 아바타·닉네임·함께한 지·수준 헤더,
   통계 타일 4종, 주간 요일 도트(스트릭), 학습 설정 5항목 수정(온보딩과 같은
   선택지 UI 재사용), Apple 계정 표시, 로그아웃 행. iOS inset grouped list 스타일
   (스펙 디자인 절).

## 완료 기준

- [ ] 온보딩 5스텝이 프로토타입 ①의 상태 5종과 대응, 건너뛰기 동작
- [ ] 프로필 5항목 수정이 목 심에 반영되고 화면에 요약 표시
- [ ] 프로필 화면이 프로토타입 ⑧과 대응(통계·도트는 픽스처)
- [ ] 터치 타깃 44pt, ~해요체 카피 규칙 준수

# S2 — AI 엔진 (배치 1, S1과 병렬)

`kickoff/README.md`의 공통 규약을 따른다. UI 없음 — 서버 라우트와 프롬프트만.
`.env.local` 필요 (`AI_GATEWAY_API_KEY`). ai-sdk 스킬 참조.

## 스코프

S0의 AI 계약 스키마를 서버 쪽에서 구현한다. 라우트는 `src/app/api/*+api.ts`(얇게),
프롬프트·판정 로직은 `src/server/`. 모델: Vercel AI Gateway 경유 **Claude Sonnet 5**
(정확한 슬러그는 게이트웨이 모델 목록에서 확인).

1. **상황 생성 라우트** — 학습자 프로필(수준·목적·장르·관심사) → 상황 카드
   (장르·제목·소개·장면·목표·내 역할·AI 역할) + **구조화된 달성 조건**. 홈 제안
   2~3개와 상황 만들기의 무작위 1개 모두 지원. 필드별 "AI가 다시 쓰기", 직접
   아이디어(한국어 허용) 입력도 이 라우트 계열. **정합성 규칙**: 역할·장면이
   바뀌면 목표는 항상 내 역할 시점으로 재작성.
2. **스토리 턴 라우트** — 대화 이력 + 학습자 입력 → 내레이션+대사 스트리밍,
   학습자 입력의 교정(오류 구간·교정문·한 줄 이유 — **초기 강도: 명백한 오류만**),
   매 턴 달성 조건 평가, 결말 연출(성공/실패/강제 — **턴 상한 30 서버 강제**).
   저항 원칙: 목표를 쉽게 내주지 않는다. 스트리밍과 구조화 출력의 병행 방식은
   세션이 설계한다.
3. **교정 스레드 라우트** — 교정 하나를 컨텍스트로 한국어 중심 Q&A + 추천 질문 칩.
4. **판정 평가 하니스** — 고정 대화록(성공 직전/명백한 실패/게이밍 시도/애매한 진행
   등) → 기대 판정 스크립트. bun로 실행, 판정 프롬프트 수정 시 회귀 확인용.

## 주의

- AI 출력 난이도·교정 강도는 학습자 프로필의 수준을 반영한다 (스펙 온보딩 절).
- 계약 스키마 변경이 필요하면 구현으로 우회하지 말고 보고에 "계약 변경 제안"으로.

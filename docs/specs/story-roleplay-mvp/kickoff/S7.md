# S7 — 배선 (Wave 2, 단독 실행. 배치 1–3 전부 머지 후 시작)

`kickoff/README.md`의 공통 규약을 따른다. `.env.local` 필요(전체 키).
이 세션부터는 공유 코드·심·계약 수정 금지가 풀린다 — 단, 수정하면 이유를 보고에
남긴다.

## 스코프

목을 실구현으로 교체하고 전체 루프를 처음으로 실데이터·실AI로 완주시킨다.

1. **인증·프로필 배선** — 로그인/온보딩/프로필 화면 ↔ Supabase 심 실구현.
   온보딩 결과가 상황 생성 개인화에 실제로 흘러들어가는지 확인.
2. **AI 배선** — 홈 제안·상황 만들기 ↔ 상황 생성 라우트, 세션 화면 ↔ 스토리 턴
   스트리밍(ai-sdk 스킬의 클라이언트 훅 참조), 교정 스레드 ↔ 스레드 라우트.
   목 지연으로 만든 로딩 상태를 실제 대기·스트리밍에 연결하고, 에러 상태(네트워크
   실패·라우트 오류)를 추가한다.
3. **기록 배선** — 세션 완료 → 결과 화면 → 서재·책 상세가 실데이터로 이어짐.
   세션 진행 중 턴 저장(이어하기의 데이터 기반 — UX는 S8).
4. **스트릭·통계** — 연속 학습일·주간 도트·프로필 통계 계산 유틸
   (`src/utils/*.test.ts` 콜로케이션 테스트 필수), 결과·프로필 화면 연결.

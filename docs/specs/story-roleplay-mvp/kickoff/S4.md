# S4 — 홈 + 상황 만들기 (배치 2, S5와 병렬)

`kickoff/README.md`의 공통 규약을 따른다. 프로토타입 화면: ② 홈, ⑥ 상황 만들기
(상태 3종). 데이터는 **목 심만** 사용(AI 응답도 계약 스키마에 맞춘 목 지연 응답)
— 실연결은 S7 소관.

## 스코프

1. **홈 탭** (`src/screens/home/`) — "오늘의 이야기" 상황 카드 2~3개(장르 태그·
   제목·소개·목표·역할 라인, 탭하면 바로 세션 시작), "나만의 상황 만들기" CTA.
2. **상황 만들기** (`src/screens/scenario-create/`) — 진입 즉시 무작위 상황 카드
   (장면/목표/내 역할/AI 역할 + 필드별 ✎), 필드 수정 시트(직접 고치기 / "AI가
   다시 쓰기"), "다른 상황 보기"(전체 재생성), 헤더 우측 "직접 만들기" 시트(한국어
   입력 허용), "이 상황으로 시작" CTA.
3. **로딩 상태 설계** — 상황 생성·재생성 대기 상태는 프로토타입에 없다. 스펙이
   "구현 시 반드시 설계"로 지정한 항목이므로 이 세션이 설계한다(목 지연으로 재현).

## 주의

- '뽑기' 어휘 금지 — "다른 상황 보기" (스펙 카피 규칙).
- 정합성 규칙(역할·장면 수정 → 목표 재작성)은 AI 계약에 있으므로, UI는 그 흐름을
  전제로 만든다(목으로 재현).

# S8 — 이어하기 + 마감 (Wave 2 마지막, S7 머지 후 시작)

`kickoff/README.md`의 공통 규약을 따른다. `.env.local` 필요(전체 키). 실기기 검증
포함 — 사용자에게 기기 연결을 요청할 수 있다.

## 스코프

1. **세션 이어하기** — 스펙이 "구현 시 반드시 설계"로 지정한 미설계 영역. 중단된
   세션의 복귀 흐름(예: 홈 진입 시 이어하기 제안, 세션 재입장 시 이력 복원)을
   설계하고 구현한다. S7이 깔아둔 턴 저장 데이터를 사용. 설계 결정은 스펙 역류
   제안으로도 남긴다(다음 스펙 개정에 반영).
2. **HIG 마감 패스** — 스펙 "구현 시 필수" 절 전체 점검: Dynamic Type(큰 글자
   설정에서 전 화면 확인), 터치 타깃 44pt 전수, 텍스트 대비(#8b95a1은 장식 캡션만),
   세이프 에어리어.
3. **실기기 설치** — `expo run:ios --device`로 사용자 iPhone에 설치, 같은 Wi-Fi의
   dev 서버로 전체 루프 1회 완주(Apple 로그인 포함).
4. **최종 self-grade** — plan.md acceptance criteria 전 항목을 채점해 보고. 미달
   항목은 사유와 함께 남긴다.

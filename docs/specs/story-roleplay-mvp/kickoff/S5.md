# S5 — 스토리 세션 + 교정 (배치 2, S4와 병렬. 가장 큰 화면 세션)

`kickoff/README.md`의 공통 규약을 따른다. 프로토타입 화면: ③ 세션(상태 4종),
④ 교정 스레드. 데이터는 **목 심만** 사용(AI 스트리밍은 목 지연·청크로 시뮬레이트)
— 실연결은 S7 소관.

## 스코프

1. **스토리 세션** (`src/screens/story-session/`) —
   - 상단: 목표 + 턴 카운터(12/30) 상시 노출, 역할 라인.
   - 채팅: 내레이션(세리프 이탤릭, 좌측 보더)과 대사 버블 혼합. 발신자 라벨 없음
     — 정렬·색·말꼬리로 구분(상대 왼쪽 회색 / 나 오른쪽 파랑).
   - 입력바: "대사 또는 *행동*을 영어로…", 행동 묘사(`*...*`) 입력 지원.
   - AI 응답 대기: 타이핑 인디케이터 + 스트리밍 표시(스펙 필수 설계 항목).
   - 결말 3종(성공/실패/강제): 마무리 내레이션 + endcard → 결과 화면으로.
2. **교정 표시** — 오류 구간만 물결 밑줄(내 버블 안), 버블 탭 → 교정 패널 펼침
   (교정문의 바뀐 부분만 파란 볼드 + 한 줄 이유 + "더 물어보기"), 오류 없는 버블은
   밑줄·패널 없음.
3. **교정 스레드** (`src/screens/correction-thread/`) — 상단 고정 교정 카드(원문
   취소선·교정문·이유), 별도 채팅 타임라인, 추천 질문 칩, 입력바.

## 완료 기준

- [ ] 프로토타입 ③의 상태 4종(진행중·결말 3종)과 ④를 재현
- [ ] 밑줄 → 패널 → 스레드 3단 동선 작동, 오류 없는 버블엔 아무 표시 없음
- [ ] 스트리밍·타이핑 인디케이터가 목으로 동작
- [ ] 채팅 스크롤(신규 메시지 추적, 키보드 회피) 자연스러움
- [ ] 터치 타깃 44pt(밑줄 버블·칩 포함)

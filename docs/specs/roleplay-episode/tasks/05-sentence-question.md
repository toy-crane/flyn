# 05. 문장 하나를 두고 더 묻는다

상태: 완료

## 전달되는 행동

첨삭 시트 하단의 `더 물어보기`를 누르면 그 문장 하나를 두고 묻는 화면이 열린다.
창 상단에 대상 문장이 인용 카드로 고정되고 헤더 서브타이틀에 원래 에피소드
이름이 남아, 어느 문장을 어디서 물고 왔는지 잃지 않는다.

주고받은 말은 저장된다. 나갔다 같은 문장에서 다시 열면 지난 내용이 이어서
나온다.

## 블로커

- **04** — 진입점이 첨삭 시트의 `더 물어보기` 하나뿐이라, 시트가 서기 전에는
  이 화면에 닿을 길이 없다.

## 완료 기준

- [x] 시트 하단 `더 물어보기`가 문장 질문 화면을 연다
- [x] 화면이 시트 위에 쌓이지 않고 push된다
- [x] 상단 인용 카드가 스크롤해도 대상 문장을 놓치지 않게 고정된다
- [x] 헤더 서브타이틀에 원래 에피소드 이름이 있다
- [x] 나갔다 같은 문장에서 다시 열면 지난 내용이 이어서 나온다
- [x] 다른 문장에서 열면 서로 섞이지 않는다

## 제약

- `sentence_question_messages`는 이 태스크가 만들고 부모 메시지를 참조한다.
  문장 질문은 문장당 하나뿐이므로 방 테이블을 만들지 않는다.
- 진입점은 첨삭 시트 하나뿐이다. 문장 질문 목록 화면은 만들지 않는다.
- 롤플레잉이 아니라 학습 질문을 주고받는 자리다. 여기서 오간 말은 에피소드
  대화에 섞이지 않고 턴으로 세지 않는다.
- 이 자리를 가리킬 때 `대화`라는 말을 쓰지 않는다. `대화`는 롤플레잉 쪽이다.

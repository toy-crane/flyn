# 01. 에피소드를 만들고 홈에서 찾는다

상태: 완료

## 전달되는 행동

앱을 열면 에피소드 목록이 홈이다. 에피소드가 하나도 없으면 목록 대신 첫
에피소드를 만들자는 안내가 보이고, 거기서 생성으로 들어간다.

생성은 한 화면 안에서 큰 제목만 바뀌며 ① 상황 → ② 역할 → ③ 목표로 진행한다.
상황은 취향과 영어 수준을 반영한 후보 3개 중에 고르고 `다른 상황 보기`가 후보
전체를 교체한다. 역할은 상대와 나를 한 화면에서 고치거나 다시 만든다. 목표 3개는
읽기 전용이고 `다른 목표 보기`로 묶어서만 다시 만든다. 이전 스텝의 결정은
내비게이션이 나르므로 본문에는 현재 질문만 남는다.

마치면 에피소드가 진행 중으로 저장된다. 홈으로 돌아오면 가장 최근 진행 중인
에피소드 하나가 상단 카드에, 나머지와 끝난 것이 `모든 에피소드`에 최근순으로
나온다. 카드에 오른 에피소드는 아래 목록에 다시 나오지 않는다. 행을 길게 누르면
에피소드를 지운다.

## 블로커

없음.

## 완료 기준

- [x] 에피소드가 없는 계정에서 홈이 첫 에피소드를 만들자는 안내만 보여준다
- [x] 3스텝이 화면 전환 없이 한 화면에서 끝나고, 이전 결정이 타이틀과 서브타이틀로 남는다
- [x] `다른 상황 보기`가 후보 3개 전체를 교체한다
- [x] 상황을 바꾸면 역할과 목표가, 역할을 바꾸면 목표가 함께 다시 만들어진다
- [x] 역할과 목표를 만드는 동안이 실제로 보이는 상태로 나타난다
- [x] 목표 3개를 직접 고칠 수 없고 `다른 목표 보기`로만 바뀐다
- [x] 만든 에피소드가 진행 중으로 저장되고 홈 카드와 목록에 나타난다
- [x] 진행 중이 둘 이상이면 카드에는 가장 최근 하나만 오르고 그 에피소드는 아래 목록에 없다
- [x] 진행 중이 하나도 없으면 카드만 사라지고 목록은 남는다
- [x] 진행 중인 행에 파란 점과 어디까지 했는지 적은 보조 줄이 있다
- [x] 에피소드를 지우면 목표까지 함께 사라진다
- [x] 턴 상한이 생성 화면 어디에도 없고, 저장된 에피소드가 생성 시점의 상한 값을 갖는다

## 제약

- 생성 호출은 두 번이다. 시나리오 후보 3개와, 선택한 시나리오의 역할·목표를
  나눠 부른다. 재생성은 해당 부분만 다시 부른다.
- 선택 즉시 역할·목표 생성을 백그라운드로 앞당기지 않는다.
- `episodes`와 `episode_goals`는 이 태스크가 만든다. 앱에는 select와 에피소드
  delete만 주고 나머지 쓰기는 service_role에 둔다.
- 턴 상한은 코드가 소유하는 시스템 상수다. 에피소드 필드로 노출해 사용자가
  정하게 만들지 않는다.
- 기존 `chat_rooms`·`chat_messages`와 채팅 화면은 여기서 건드리지 않는다. 폐기는
  02가 대화 화면을 대신 세울 때 함께 한다.
- 이 태스크가 끝난 시점에는 에피소드를 열 대화 화면이 아직 없다. 카드와 목록
  행의 목적지는 02가 연결한다.

# 02. 에피소드 안에서 롤플레잉한다

상태: 시작 전

## 전달되는 행동

홈의 카드나 목록 행에서 에피소드를 열면 대화 화면이 뜬다. 네이티브 헤더가
시나리오 제목과 역할을 말하고, 대화 목록의 첫 요소인 상황 카드가 `상황 자세히
보기`로 제자리에서 펼쳐진다. composer 바로 위 목표 바는 접히면 지금 할 목표 한
줄, 펼치면 같은 자리에서 턴 진행과 목표 3개 전체를 보여준다.

`영어로 써 보세요`에 영어를 쓰면 원문 그대로 전달되고, 한글을 쓰면 번역된 영어가
전달된다. 말풍선에는 언제나 실제로 전달된 문장이 남는다. 상대는 어색한 영어도
의도를 선해해 롤플레잉으로 반응하고, 정말 알아들을 수 없을 때만 되묻는다. 응답은
스트리밍으로 도착한다.

도중에 나가면 에피소드는 진행 중으로 남고, 홈의 `대화 이어가기`로 돌아오면
지난 대화 그대로 이어서 한다.

## 블로커

- **01** — 대화할 에피소드와 역할·목표가 있어야 이 화면이 성립하고, 유일한
  진입점인 홈도 01이 세운다.

## 완료 기준

- [ ] 홈 카드와 목록 행에서 대화 화면으로 들어간다
- [ ] 헤더·상황 카드·목표 바가 같은 정보를 두 곳에서 반복하지 않는다
- [ ] 상황 카드가 대화 목록 첫 요소에서 제자리로 펼쳐지고 접힌 라벨이 `상황 자세히 보기`다
- [ ] 헤더에 `목표` 버튼 없이 목표 바가 탭 없이 항상 보인다
- [ ] 턴 진행은 목표 바를 펼쳤을 때만 보인다
- [ ] 영어로 쓰면 원문이 전달되고 교정본이 대신 나가지 않는다
- [ ] 한글로 쓰면 번역된 영어가 전달되고 말풍선에 그 영어가 남는다
- [ ] 어색한 영어에도 상대가 되묻지 않고 롤플레잉을 이어간다
- [ ] 대화 도중 나갔다 돌아오거나 앱을 다시 켜도 지난 대화가 그대로 이어진다
- [ ] `chat_rooms`·`chat_messages`와 채팅 화면·라우트가 저장소에서 사라진다

## 제약

- 스트리밍, 메시지 소유권, 스크롤·키보드 경계, 재시도는 기존 채팅 구현을
  재사용한다. 새로 설계하지 않는다.
- `episode_messages`는 이 태스크가 만들고 **전달된 문장만** 담는다. 사용자가
  입력한 원문은 03의 판정 행이 갖는다.
- 한글 입력은 막힐 때 쓰는 비상구다. 기능은 온전히 두되 문구와 배치에서
  앞세우지 않는다.
- 한글을 어느 호출이 번역할지는 이 태스크가 정한다. 판정은 롤플레잉과 병렬로
  돌아 전달 전에 끝나지 않으므로 번역을 맡을 수 없다.
- 목표 달성 표시와 종료는 아직 없다. 목표 바는 첫 목표를 지금 할 목표로 두고,
  말풍선 옆 표시 자리는 비워 둔다.

# 04 — 아이콘 줄이 메시지가 끝난 뒤 떠오른다

## Outcome

장면이나 답변이 흐르는 동안에는 말풍선 아래에 아무것도 없다가, 다 도착하면 아이콘 줄이 대사마다 위에서부터 차례로 떠오른다. 줄의 자리는 처음부터 잡혀 있어 말풍선이 밀리지 않는다. 새 스토리 1화의 첫 장면은 복사만 먼저 서고, 사용자가 첫 메시지를 보내 회차가 생기면 책갈피가 같은 떠오름으로 복사 옆에 자리 잡는다. 2화부터는 첫 장면도 다른 장면과 같다. 이미 끝난 대화를 열거나 돌아왔을 때는 애니메이션 없이 서 있고, 동작 줄이기를 켜면 떠오름 없이 나타난다.

## Blockers

작업 03. 떠오르는 것이 03이 정한 줄이라, 그 줄이 먼저 있어야 한다.

## Acceptance criteria

- [x] 장면이 흐르는 동안 말풍선 아래에 아이콘이 없고, 장면이 끝나면 대사마다 40ms 간격으로 차례로 떠오른다. 줄이 나타날 때 대화가 밀리지 않는다.
- [x] AI에게 물어보기의 답변 아래 줄도 같은 때에 같은 움직임으로 나타난다.
- [x] 대화 기록을 열거나 다른 화면에서 돌아오면 줄이 애니메이션 없이 처음부터 서 있다.
- [x] 새 스토리 1화를 열면 첫 장면 아래에 복사만 있고, 첫 메시지를 보내면 그 옆에 책갈피가 같은 떠오름으로 나타난다. 2화의 첫 장면에는 처음부터 복사와 책갈피가 함께 있다.
- [x] 다시 받기나 수정으로 장면을 새로 받으면 새 장면의 줄도 같은 규칙으로 나타난다.
- [x] 동작 줄이기를 켜면 줄이 애니메이션 없이 같은 때에 나타난다.
- [x] 흐르는 동안 흐릿하게 서 있던 책갈피와 회차 전 첫 장면의 빈 줄은 사라진다. [표현 노트 작업 기록](../../saved-expressions/tasks/01-save-from-episode.md)의 두 수정이 이 스펙으로 대체되었음을 그 기록에 남긴다. [모바일 채팅 메시지 동작](../../../decisions/mobile-chat-message-actions.md)이 줄이 나타나는 때를 담는다.

## Constraints

- 때와 움직임은 [시안](../prototypes/icon-row-entrance.html)과 같다. 값은 [스펙](../spec.md)의 가정(불투명도 0에서 1, 4pt 위로, 180ms, 대사 사이 40ms)을 기본으로 하고 기기에서 조정할 수 있다.
- 회차가 첫 메시지에 생긴다는 [AI 에피소드 프로토콜](../../../decisions/ai-episode-protocol.md)과 열기만 한 플레이를 기록에 남기지 않는 [모바일 스토리 탐색](../../../decisions/mobile-story-browsing.md)은 바꾸지 않는다. 첫 장면의 책갈피를 미리 두는 길은 이 작업의 범위 밖이다.
- 스트리밍 중 스크롤 추적과 최신 메시지 이동은 [모바일 채팅 스크롤](../../../decisions/mobile-chat-scrolling.md)을 따른다. 물어보기 시트의 답변 줄은 [모바일 AI에게 물어보기](../../../decisions/mobile-ask-ai.md)의 시트 안에서 같은 규칙이다.

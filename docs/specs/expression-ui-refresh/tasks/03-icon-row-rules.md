# 03 — 아이콘 줄이 한 규칙으로 움직인다

## Outcome

AI에게 물어보기의 답변 아래, 인물 대사 아래, 배울 표현 아래, 기억해 둘 표현 카드, 표현 노트 카드에 서는 아이콘 줄이 같은 규칙으로 움직인다. 아이콘의 그림 사이는 8pt이고, 누르는 동안 배경이 그려지지 않으며, 눌렀다는 답은 아이콘 자신이 한다. 복사는 1.5초 동안 체크로 바뀌었다가 돌아온다. 누르는 순간 가벼운 햅틱이 한 번 오고, 토스트가 뜰 때 주던 햅틱은 사라진다.

## Blockers

None.

## Acceptance criteria

- [x] 아이콘의 그림과 그림 사이가 8pt다. 버튼 하나의 누르는 범위(가로 28pt, 세로 40pt)는 그대로다.
- [x] 누르는 동안 iOS의 하이라이트 원과 Android의 물결이 없다. 살짝 작아지는 동작은 남는다.
- [x] 복사를 누르면 아이콘이 체크로 바뀌었다가 1.5초 뒤 돌아온다. 책갈피는 채워지거나 비고, 다시 받기는 진행 표시로 바뀐다. 줄이 움직이지 않는다.
- [x] 아이콘 줄의 버튼을 누르는 순간 가벼운 햅틱이 한 번 온다. 책갈피는 토스트까지 합쳐 한 번이다. 햅틱을 지원하지 않는 기기에서도 나머지 동작은 같다.
- [x] 두 버튼의 누르는 범위가 겹치는 4pt 띠를 눌렀을 때 어느 쪽이 눌리는지 정해져 있고 기기에서 그대로다.
- [x] 접힌 배울 표현 한 줄의 쉐브론, 수정 그만두기, 최신 메시지 버튼처럼 줄 밖의 작은 아이콘 버튼은 바뀌지 않는다.
- [x] 프로젝트 `Icon`에 체크와 휴지통이 있다.
- [x] [모바일 채팅 메시지 동작](../../../decisions/mobile-chat-message-actions.md)이 그림 사이 8pt, 눌림 배경 없음, 햅틱, 아이콘 상태로 답하는 규칙을 담고, "복사 성공 알림을 두지 않는다"가 토스트 같은 알림을 뜻함을 밝힌다. [모바일 아이콘 렌더링](../../../decisions/mobile-icon-rendering.md)이 새 아이콘을 반영한다.

## Constraints

- 간격과 눌림 반응은 [시안](../prototypes/icon-row.html)과 같다. 값의 근거는 [스펙](../spec.md)의 `메시지 아래 아이콘 줄`이다.
- 버튼 안 진행 표시의 크기와 자리는 [모바일 작업 진행 표시](../../../decisions/mobile-action-progress.md)를 따른다.
- 같은 역할의 조합과 간격을 다섯 자리에서 같게 맞추는 기준은 [모바일 UI 일관성 검토](../../../decisions/mobile-ui-consistency-review.md)를 따른다.
- 줄이 나타나는 때는 이 작업에서 바꾸지 않는다. 작업 04가 맡는다.

## Verification

- `bun run test`가 복사 아이콘의 체크 전환과 복원, 햅틱 한 번, 눌림 배경 없음을 확인하는 테스트를 포함해 통과한다.
- `bun run check`가 통과한다.
- `agent-device` 한 세션에서 iOS와 Android 각각 다섯 자리의 줄을 열어 간격, 눌림 배경 없음, 복사의 체크 전환을 확인하고, 겹치는 띠를 눌러 어느 쪽이 눌리는지 확인한다. Android는 물결이 사라졌는지 본다.

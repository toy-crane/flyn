# 02 — 저장 토스트가 상황 줄 밑에서 나온다

## Outcome

사용자가 대화에서 인물 대사의 책갈피를 누르면 `표현을 저장했어요.` 토스트가 상황 줄 바로 밑에서 미끄러져 나와 대화 위에 뜨고, 2.5초 뒤 나온 자리로 도로 들어간다. 헤더와 상황 줄은 가려지지 않는다. 문구, 알약 모양, 방금 누른 책갈피와 같은 아이콘, 연달아 누르면 문구 하나만 서는 규칙은 그대로다.

## Blockers

None.

## Acceptance criteria

- [x] 대화 화면에서 토스트가 상황 줄 밑에서 나오고 헤더와 상황 줄을 덮지 않는다. 저장 취소의 `저장을 취소했어요.`도 같은 자리다.
- [x] 토스트가 대화 위에 떠서 말풍선을 밀지 않고, 2.5초 뒤 나온 자리로 도로 들어간다.
- [x] 연달아 누르면 문구 하나만 서 있고 서 있던 시간을 새로 센다.
- [x] 키보드가 올라온 채 저장해도 토스트가 가려지지 않는다.
- [x] 큰 접근성 글자 크기에서 상황 줄이 두 줄이 되어도 토스트는 그 밑에서 나온다. 밝은 화면과 어두운 화면에서 알약이 대화와 구분된다.
- [x] 화면 읽기가 토스트 문구를 읽는다.
- [x] [모바일 AI 채팅 표현](../../../decisions/mobile-ai-chat-rendering.md)과 [표현 노트 스펙](../../saved-expressions/spec.md)의 "화면 위쪽에 뜬다"가 이 자리로 바뀐다.

## Constraints

- 자리와 움직임은 [시안](../prototypes/toast.html)과 같다. 자리를 정하는 규칙은 [모바일 토스트 자리](../../../decisions/mobile-toast-placement.md)가 소유한다.
- 상황 줄의 위치와 수명은 [모바일 에피소드 상황 줄](../../../decisions/mobile-episode-situation-line.md)을 따른다. 키보드와 겹치는 자리는 [모바일 키보드 회피](../../../decisions/mobile-keyboard-avoidance.md)를 따른다.
- 토스트가 뜰 때 주던 햅틱은 이 작업에서 손대지 않는다. 작업 03이 누르는 순간의 햅틱으로 옮긴다.
- 표현 돌아보기 화면의 토스트는 작업 06에서 같은 장치로 띄운다.

## Verification

- `bun run check`가 통과한다.
- `agent-device` 한 세션에서 책갈피를 누르고, 취소하고, 연달아 누르고, 키보드를 올린 채 누르는 네 경우의 토스트 자리를 확인한다.

## Execution

- Verification: 2026-09-10. `bun run test` 83개 파일 581개 검사 통과, `bun run check` 통과. `screen-toast.test.tsx`가 띠 아래 자리, 2.5초 뒤 사라짐, 연달아 알릴 때 문구 하나와 시간 다시 세기, 화면 읽기의 `polite` 영역, 알약이 커질 때 층도 높아지는 것을 확인한다. `chat-panel.test.tsx`가 토스트 층의 자리(헤더 아래에서 시작해 상황 줄 높이만큼 내려옴), 목록보다 위에 서는 순서, 목록 시작점이 밀리지 않는 것을 확인한다. `episode-screen.test.tsx`가 담기와 취소의 두 문구가 같은 자리에 뜨는 것을 확인한다. iOS 시뮬레이터 `flyn-slot-1` 한 세션에서 로그인부터 이어서, 책갈피를 담고 취소해 알약이 상황 줄 밑에서 나와 말풍선 위에 뜨는 것, 소프트 키보드를 올린 채 저장해도 가려지지 않는 것, `accessibility-extra-extra-large`에서 상황 줄이 세 줄이 되어도 그 밑에서 나오고 잘리지 않는 것, 어두운 화면에서 알약이 대화와 구분되는 것을 화면으로 확인했다.
- Blocker: —
- Revision: 기기 확인에서 두 가지를 고쳤다. 첫째, 토스트 층이 목록보다 먼저 그려져 알약이 말풍선 뒤로 깔렸다. `zIndex`와 `elevation`을 주어 위로 올렸다. 둘째, 큰 접근성 글자에서 알약이 위아래로 잘리고 화면 끝에 닿았다. 층 높이를 상수가 아니라 그려진 알약을 재서 잡고, 층에 대화와 같은 좌우 여백을 주고, 줄높이를 클래스가 아니라 배율을 곱한 값으로 두었다. 그 위에 문구의 확대 한도를 1.6배로 두었다. 좁은 크롬에만 확대 제한을 둘 수 있다는 [모바일 타이포그래피](../../../decisions/mobile-typography.md)의 예외를 따른 것이고, 본문인 말풍선과 카드에는 제한이 없다.

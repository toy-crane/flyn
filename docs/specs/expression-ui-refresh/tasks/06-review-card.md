# 06 — 기억해 둘 표현이 노트와 같은 카드를 쓴다

## Outcome

표현 돌아보기의 `기억해 둘 표현` 카드가 표현 노트 카드와 같은 카드다. 첫 줄만 출처 대신 채널 색과 반짝임 아이콘이 있는 상황이고, 아래는 영어 문장과 한국어 뜻이다. 카드를 누르면 `내가 쓴 문장`과 `이렇게 쓰는 이유`가 펼쳐지고 `다른 예문`은 없다. 목록 제목 옆의 개수가 사라진다. 카드 아래 오른쪽에 복사와 책갈피가 서고, 책갈피는 대화에서 같은 메시지의 배울 표현을 저장하는 것과 같은 항목을 만들며 토스트가 헤더 밑에서 나온다.

## Blockers

작업 05. 같은 카드를 쓴다.
작업 02. 헤더 밑 토스트가 02가 만든 장치다.

## Acceptance criteria

- [x] 기억해 둘 표현의 카드가 노트 카드와 같은 크기, 같은 글자, 같은 여백이고 첫 줄만 쓰는 상황이다.
- [x] 카드 어디를 눌러도 펼쳐지고 펼친 안은 `내가 쓴 문장`과 `이렇게 쓰는 이유`뿐이다. `내 대화와 다른 예문` 줄, 구분선, `다른 상황에서` 라벨과 예문이 없다. 카드는 접힌 채 열린다.
- [x] 목록 제목 `기억해 둘 표현` 옆에 개수가 없다.
- [x] 카드 아래 오른쪽에 복사와 책갈피가 있다. 복사는 고친 문장을 클립보드에 넣는다.
- [x] 여기서 책갈피를 누르면 표현 노트 맨 위에 그 문장이 생기고, 대화로 돌아가면 같은 메시지의 책갈피가 채워져 있다. 대화에서 먼저 저장한 표현은 여기서 채워진 채로 보인다.
- [x] 저장과 취소에 헤더 밑에서 나오는 토스트가 뜬다. 헤더는 가려지지 않는다.
- [x] 화면 위쪽의 스토리와 화 표시, 다음 이야기 예고, 하단 버튼, 뒤로 가기와 홈 아이콘은 그대로다.
- [x] 서버가 예문을 만들고 저장하는 것은 그대로다. 화면에서만 빠진다.
- [x] 큰 접근성 글자 크기와 어두운 화면에서 카드와 펼친 안, 아이콘 줄, 토스트가 겹치거나 잘리지 않는다.
- [x] [에피소드 종료와 표현 돌아보기 스펙](../../episode-expression-review/spec.md)의 "카드를 펼치면 예문이 보인다"와 목록 제목 옆 개수가 이 카드로 바뀐다.

## Constraints

- 카드 모양은 [시안](../prototypes/review.html)과 같다. 토스트 자리는 [모바일 토스트 자리](../../../decisions/mobile-toast-placement.md)를 따른다.
- 첫 줄의 채널 색과 반짝임 아이콘은 [모바일 대화 중 교정](../../../decisions/mobile-episode-correction.md)의 교정과 안내 채널을 그대로 쓴다.
- 위쪽 표시와 예고의 문구는 [스토리 진행·결말 화면 표기](../../../decisions/story-progress-and-ending-display.md)를 따르며 바꾸지 않는다.
- 대화 중 말풍선 아래에 붙는 배울 표현 카드는 바꾸지 않는다.

  서는 것을 확인했다. 저장소의 `hydrate`가 서버가 아는 자리보다 남아 있던 실패

  그대로 남는다. 다른 대화로 옮겨 갈 때 아직 돌아오지 않은 요청을 끊지 않던 것도

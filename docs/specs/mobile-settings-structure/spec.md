# 모바일 설정 구조 명세

## 목표

- 사용자가 현재 탭에서 설정으로 자연스럽게 이동하고, 뒤로 가기로 같은 자리로
  돌아오게 한다.
- 설정 항목을 성격에 따라 묶어 필요한 항목과 위험한 동작을 빠르게 구분하게 한다.
- 여러 값 중 하나를 고르는 설정은 모든 선택지와 현재 값을 한 화면에서 확인하게
  한다.
- 행 오른쪽의 표시만 보고도 다음 화면 이동, 외부 이동, 즉시 실행과 현재 값을
  구분하게 한다.
- 계정 삭제는 찾을 수 있으면서도 실수로 실행하지 않도록 마지막 확인을 유지한다.

## 사용자에게 보이는 결과

- 설정은 시트가 아니라 현재 탭 위에 밀려 들어오는 `설정` 화면으로 열린다.
  화면을 열면 탭 막대는 가려지고, 닫기 버튼 대신 뒤로 가기 쉐브론이 보인다.
- 설정에서 `프로필`, `화면 모드` 같은 하위 화면을 열면 같은 화면 흐름 위에
  이어진다.
- 설정 첫 화면은 프로필 머리말, `계정`, `환경 설정`, `앱 정보`, 계정 삭제 순서로
  보인다.
- `화면 모드` 행은 현재 값을 보여 주고, 전용 화면에서 `라이트`, `다크`,
  `시스템 설정` 중 하나를 고르게 한다.
- 계정 삭제만 빨간 글자로 표시된다. 로그아웃은 일반 계정 동작으로 보인다.

## 확정 범위

### 설정을 여는 방식

- 홈에서 설정을 열면 현재 탭 위를 덮는 전체 화면으로 `설정`을 연다. 설정 화면에서는
  탭 막대를 보여 주지 않는다.
- 설정 첫 화면은 운영체제의 헤더와 `설정` 제목을 사용한다. 오른쪽 닫기 버튼은
  두지 않는다.
- 뒤로 가기는 쉐브론만 보여 주고 이전 화면 이름을 붙이지 않는다. iOS 가장자리
  스와이프와 Android 뒤로 가기 제스처·버튼도 같은 탭으로 돌아간다.
- `프로필`과 `화면 모드`는 설정 위에 이어지는 일반 하위 화면이다. 각 화면에서
  뒤로 가면 설정의 같은 스크롤 흐름으로 돌아온다.

### 설정 첫 화면의 그룹

- 화면 위에는 현재 프로필 사진, 닉네임과 아이디를 가운데 정렬해 보여 준다. 프로필
  사진과 `프로필` 행은 모두 같은 `프로필` 화면을 연다.
- `계정` 섹션은 `프로필`, `로그아웃` 순서다.
- `환경 설정` 섹션은 `알림`, `햅틱 반응`, `화면 모드` 순서다.
- `앱 정보` 섹션은 `버전`을 보여 준다.
- `계정 삭제`는 제목 없는 단독 섹션으로 화면 맨 아래에 둔다.
- 각 설정 항목은 한 개의 행과 한 개의 누르기 영역만 가진다. 섹션 제목이나 행
  안쪽 일부에 별도 동작을 겹쳐 두지 않는다.

### 여러 값 중 하나 선택

- `화면 모드` 행에는 현재 선택한 `라이트`, `다크`, `시스템 설정` 중 하나를
  값으로 보여 준다.
- 행을 누르면 제목이 `화면 모드`인 전용 화면을 연다. 메뉴, 드롭다운, 같은 화면의
  임시 패널이나 단일 선택 대화상자로 대신하지 않는다.
- 선택 화면은 세 값을 항상 모두 보여 주고 현재 값 하나에만 선택 표시를 둔다.
  iOS는 체크 표시를, Android는 라디오 버튼을 사용한다.
- 값을 고르면 즉시 앱 전체에 적용한다. 선택 화면은 자동으로 닫히지 않고 새 화면
  모드로 계속 보인다.
- 설정으로 돌아오면 행의 값이 새 선택으로 바뀌어 있다.
- 선택한 값은 이 기기에서 앱을 다시 열어도 유지한다. 저장된 값이 없는 기존 설치와
  새 설치는 `시스템 설정`으로 시작한다.
- `시스템 설정`을 고른 동안에는 앱을 다시 열지 않아도 운영체제 화면 모드 변경을
  따른다.

### 행 오른쪽 표시

- 앱 안의 하위 화면을 여는 행은 iOS에서 쉐브론을 보여 준다. Android는 Material
  설정 표현을 유지하고 iOS 쉐브론을 복사하지 않는다.
- 현재 값도 보여 주는 이동 행은 값과 이동 표시를 함께 전달한다. `화면 모드`는
  iOS에서 현재 값 뒤에 쉐브론을 두고, Android에서는 현재 값만 보여 준다.
- 앱 밖의 주소나 다른 앱을 여는 행이 생기면 외부 이동 글리프를 보여 준다.
- 로그아웃처럼 즉시 작업을 실행하는 행과 계정 삭제처럼 확인창을 여는 행에는
  쉐브론이나 외부 이동 글리프를 두지 않는다.
- 스위치는 행 오른쪽의 스위치 자체가 상태와 동작을 나타낸다.
- 버전처럼 누를 수 없는 정보 행은 오른쪽에 값만 보여 준다.
- 작업 중 진행 표시는 해당 행의 오른쪽에 잠시 나타날 수 있다. 진행 중에도 행의
  이름과 자리는 바꾸지 않는다.

### 파괴적 동작

- `로그아웃`은 `계정` 섹션의 일반 글자색 행이다. 아이콘, 쉐브론과 채운 배경을
  두지 않는다. 누르면 현재 기기에서 로그아웃한다.
- 로그아웃이 진행되는 동안 같은 요청을 다시 시작할 수 없다. 행의 이름은 유지하고
  오른쪽에 진행 상태를 보여 준다. 실패하면 현재 화면에서 다시 시도할 수 있다.
- `계정 삭제`는 화면 맨 아래 제목 없는 단독 섹션에 둔다. 글자만 시스템의 위험
  색으로 표시하고 아이콘, 쉐브론과 채운 배경을 두지 않는다.
- 계정 삭제 행 아래에는 상시 설명을 두지 않는다. 위치, 여백과 글자색이 평소 경고를
  맡는다.
- 계정 삭제를 누르면 다른 화면으로 이동하지 않고 플랫폼 확인창을 연다. 확인창은
  삭제가 되돌릴 수 없고 다시 가입해도 이전 정보가 돌아오지 않는다는 점을 알린다.
- 확인 뒤 삭제가 진행되는 동안 문구는 `계정 삭제`로 유지하고 오른쪽에 진행 상태를
  보여 준다. 같은 요청을 다시 시작할 수 없다.
- 삭제에 실패하면 로그인 상태와 현재 화면을 유지하고 같은 단독 섹션에서 다시
  시도할 수 있게 한다. 삭제가 끝나면 로그인 화면으로 이동한다.
- `프로필` 화면에서는 계정 삭제를 제거한다. 그 화면은 프로필 사진, 닉네임과
  아이디 편집만 맡는다.

## 수용 기준

- 홈에서 설정을 열면 시트가 아니라 전체 화면으로 열리고 탭 막대가
  가려진다.
- 설정 첫 화면에 닫기 버튼이 없고, 뒤로 가기 쉐브론과 시스템 뒤로 가기로 원래
  탭의 같은 자리로 돌아간다.
- iOS와 Android에서 프로필 머리말, `계정`, `환경 설정`, `앱 정보`, 제목 없는 계정
  삭제 섹션이 확정된 순서로 보인다.
- `계정`에는 `프로필`, `로그아웃`만 있고, `환경 설정`에는 `알림`, `햅틱 반응`,
  `화면 모드`만 있으며, `앱 정보`에는 `버전`이 있다.
- 프로필 사진과 `프로필` 행이 같은 화면을 연다.
- `화면 모드` 행이 현재 값을 보여 주고, 누르면 세 선택지가 모두 보이는 전용 화면을
  연다.
- 선택 화면 제목과 설정 행 이름이 모두 `화면 모드`다. 현재 값 하나에만 선택
  표시가 있고 화면 읽기 기능도 그 값을 선택됨으로 전달한다.
- 화면 모드를 고르면 선택 화면이 닫히지 않은 채 바로 새 모드로 바뀐다. 뒤로 가면
  설정 행의 값과 설정 화면도 같은 모드로 보인다.
- `라이트`와 `다크`는 앱을 다시 열어도 유지된다. `시스템 설정`은 앱이 열린 동안의
  운영체제 화면 모드 변경도 따른다.
- iOS의 `프로필`과 `화면 모드` 이동 행에는 쉐브론이 있고 Android에는 같은
  쉐브론이 없다. `화면 모드`는 두 플랫폼 모두 현재 값을 보여 준다.
- 스위치 행은 스위치, 버전 행은 값, 로그아웃과 계정 삭제 행은 평소 아무 오른쪽
  표시도 사용하지 않는다.
- 설정에서 빨간 글자는 `계정 삭제` 하나뿐이다. 로그아웃은 일반 글자색이고 계정
  삭제는 화면 맨 아래에 단독으로 보인다.
- 계정 삭제 행 아래에는 상시 설명이 없고, 누른 뒤 확인창에서 되돌릴 수 없음을
  확인한다.
- `프로필` 화면에는 계정 삭제가 없다.
- 로그아웃과 계정 삭제의 진행, 실패와 중복 실행 차단이 기존 동작을 유지한다.
- iOS와 Android 개발 빌드에서 라이트, 다크, 큰 글자, VoiceOver 또는 TalkBack과
  시스템 뒤로 가기를 확인한다.
- 모바일의 자동 검사와 타입 검사가 통과한다.

## 확정 제약과 이유

- 설정은 잠깐 열었다 닫는 독립 시트가 아니라 프로필과 선택 화면으로 이어지는
  설정 계층이다. 일반 화면 전환은 첫 화면과 하위 화면에 같은 뒤로 가기 흐름을 준다.
- 그룹 이름은 행의 기능이 아니라 사용자가 찾는 대상에 맞춘다. 계정, 환경 설정과
  앱 정보를 나누면 즉시 실행, 저장된 선택과 읽기 전용 정보가 섞이지 않는다.
- 여러 값을 메뉴에 숨기지 않는다. 전용 화면은 가능한 값, 현재 선택과 선택 뒤
  결과를 한 번에 보여 준다.
- 오른쪽 표시는 누를 수 있다는 장식이 아니라 행이 일으키는 결과를 말한다. 모든
  누를 수 있는 행에 쉐브론을 붙이면 내부 이동과 실행을 구분할 수 없다.
- 계정 삭제의 마찰은 상시 설명이 아니라 확인창이 맡는다. 평소에는 마지막 위치와
  빨간 글자가 위험을 알리고, 실제 실행 직전에 결과를 다시 밝힌다.
- 로그아웃을 일반 계정 동작으로 두어 같은 화면의 위험 색은 되돌릴 수 없는 계정
  삭제에만 사용한다.

## 가정

- 화면 모드 선택은 계정이 아니라 기기에 속한다. 같은 계정의 다른 기기와 동기화하지
  않고, 한 기기에서 계정을 바꿔도 마지막 선택을 유지한다.
- 현재 설정에는 외부 이동 행이 없다. 외부 이동 글리프 규칙은 그런 행을 추가할
  때 적용한다.
- `알림`과 `햅틱 반응`의 저장 범위와 실제 기능은 이번 작업에서 바꾸지 않는다.

## 제외

- 프로필 사진, 닉네임과 아이디의 편집·저장 규칙 변경.
- 알림 권한 요청, 알림 전송과 햅틱 동작의 실제 연결 또는 저장 방식 변경.
- 이용약관, 개인정보 처리방침, 구독, 사용량이나 다른 설정 행 추가.
- 라이트와 다크 팔레트 자체의 변경 또는 새 브랜드 색상 추가.
- 탭의 정보 구조나 탭 구성 변경.
- 계정 삭제가 지우는 서버 데이터, 권한과 삭제 순서 변경.
- 별도 계정 삭제 안내 화면, 재로그인이나 확인 문구 입력 추가.

## 유보

- 화면 모드 선택을 계정에 저장해 여러 기기에서 맞출지.
- 외부 이동 행이 처음 생겼을 때 플랫폼별 외부 이동 글리프의 구체적인 모양.

## 남은 위험

- 화면 모드가 바뀌는 순간 선택 화면, 그 뒤의 설정, 운영체제 헤더와 탭 화면이 한
  프레임 안에서 같은 모드로 갱신되지 않을 수 있다.
- 설정을 시트에서 일반 화면으로 바꾸면 투명 헤더의 상단 여백, 탭 막대 가림과
  원래 탭의 스크롤 위치 복원에 회귀가 생길 수 있다.
- iOS 체크 표시와 Android 라디오 버튼이 보이는 선택 상태를 화면 읽기 기능에 같은
  뜻으로 전달하는지는 실제 개발 빌드에서 확인해야 한다.
- 기기에 저장된 예전 화면 모드 값이 없거나 읽히지 않을 때 `시스템 설정`으로 안전하게
  돌아오는지 확인해야 한다.

# 모바일 내비게이션 테스트가 전체 실행에서 간헐적으로 실패한다

## 증상

`bun run test`로 전체 스위트를 돌리면 `apps/mobile`의 두 파일이 간헐적으로 실패한다.

- `src/core/navigation/auth-routing.test.tsx`
- `src/core/navigation/onboarding-routing.test.tsx`

한 번의 실행에서 21개 테스트가 실패했고, 실패한 스위트의 소요 시간이 각각 11초와 62초로 평소보다 길었다.

## 확인한 근거

- 같은 두 파일만 따로 돌리면 통과한다. 두 파일 23개가 3.8초에 모두 통과했다.
- 이 세션의 변경이 없는 깨끗한 `HEAD` 워크트리에서도 같은 실패가 재현됐다. 같은 워크트리에서 다시 돌리자 6개가 2.2초에 모두 통과했다.
- 전체 스위트를 다시 돌리자 550개가 모두 통과했다.
- 최근 GitHub Actions의 `Validate (test)` 실행은 계속 성공했다.

## 추정 원인

병렬 부하에서 타이머나 비동기 세션 복원이 느려져 대기 시간을 넘긴다. 코드 결함이 아니라 테스트의 시간 의존성으로 보인다.

## 다음 단계

두 파일의 대기 방식을 `waitFor` 기준으로 다시 보고, 고정 시간에 기대는 부분이 있으면 상태 변화 대기로 바꾼다. 이 세션의 CI 워크플로 변경 범위 밖이라 손대지 않았다.

# 앱을 연 채 글자를 키우면 기존 사용자 말풍선이 잘린다

## 관찰한 현상

2026-09-07 `kim의 iPhone`의 iPhone 14에서 Flyn을 연 채 iOS 설정의 텍스트
크기를 50%에서 100%로 바꿨다. 기존 사용자 말풍선과 이미 펼친 교정 카드의 글자는
커졌지만 이전 크기의 배치를 유지해 오른쪽과 아랫부분이 잘렸다. 새로 펼친 카드는
정상으로 표시됐다. React Native는 0.86.3이다.

교정 카드는 `useWindowDimensions().fontScale`이 바뀔 때 내부 네이티브 뷰를 다시
만들어 해결했다. 카드의 펼침 상태는 유지한다. 같은 기기에서 100% → 50% → 100%로
바꿔 기존 한국어 카드의 제목, 영어 문장, 설명과 버튼이 다시 배치됨을 확인했다.
교정 출처와 확인 상태 줄에도 같은 처리를 적용했다.

사용자 말풍선은 이번 교정 개선의 범위 밖이므로 바꾸지 않았다. 글자 크기를 바꾼 뒤
기존 말풍선이 잘리는 현상과 네이티브 텍스트 배치의 원인은 남아 있다.

## 다음 확인

화면이 글자 크기 변경을 받는 경로와 React Native 텍스트의 배치 갱신을 작은 예제로
확인한다. 목록의 행 높이 기억과 텍스트 측정 중 어느 쪽이 원인인지 구분한 뒤,
공통 메시지 UI의 정상 줄바꿈을 검증한다. 근본 해결을 찾으면 교정 카드의 재생성
처리도 없앨 수 있는지 확인한다.

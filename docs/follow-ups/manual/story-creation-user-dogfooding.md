# 사용자가 두 화짜리 스토리의 재미를 확인한다

**Symptom**: 실제 사용자가 원하는 상황을 경험했는지와 계속 플레이하고 싶은지는 확인하지 않았다. 에이전트의 플레이와 자동 평가를 사용자의 답으로 대신할 수 없다.

**Observed evidence**: [실제 앱 검증 기록](../../../apps/api/eval/results/story-evaluation-review-2026-09-13.md)에는 에이전트가 iOS에서 두 화를 완주한 경로가 있다. 사용자 답은 기록되지 않았다.

**Suspected cause**: 사용자 경험에 관한 질문이라 앱 실행과 기계 검사만으로 판단할 수 없다. 제품 결함이 있다고 단정하지 않는다.

**What was tried**: 에이전트가 두 화를 완주했고 자동 평가를 실행했다. 실제 사용자의 재미 확인은 아직 하지 않았다.

**Proposed next step**: 사용자가 원하는 두 상황을 플레이 전에 정하고 화 사이의 제작 인터뷰 없이 끝까지 플레이한다. 원하는 상황이 실제로 나왔는지, 상황을 알고 시작해도 다음 전개가 궁금했는지, 앞 화의 선택이 다음 화에 영향을 줬다고 느꼈는지 묻고 답을 기록한다. 인터뷰가 길어서 첫 플레이를 미루게 되는지와 `에피소드 추가하기`로 다음 상황을 떠올릴 수 있는지도 살핀다. 승인된 동작은 [스토리 만들기 결정 계약](../../decisions/story-creation.md)을 따른다.

# 스토리 만들기 재시도와 표지 실패 경로를 확인한다

## 남은 문제

API 연결을 끊은 실기기 검증에서 iOS와 Android 모두 실패 알림을 보여 줬다.
Android에서는 닫은 뒤 같은 카드와 버튼, 안내가 돌아왔다. 같은 카드에서 다시
시도해 성공하는 경로와 표지 생성만 실패해 빈 색 상자로 상세가 열리는 경로는 실제
화면에서 확인하지 않았다. iOS의 닫기 뒤 복원도 세션 재시작 때문에 확인하지 못했다.

  Android 생성은 다시 실행하지 않았다.

## 다음 확인

- 두 플랫폼에서 실패 알림을 닫고 카드, 원래 버튼 문구, 카드 뒤 안내가 남는지 본다.
  같은 카드의 `다시 시도`로 생성이 성공하고, 실패한 시도가 `내 스토리`에 남지
  않는지 확인한다.
- 표지 생성만 실패시키고 스토리가 저장되어 상세가 빈 색 상자로 열리는지 확인한다.
  표지만 실패한 경우와 대본 실패를 구분한다.
- 대본, 표지, 저장 단계의 버튼 문구가 서버의 실제 완료 순서에 맞게 바뀌는지 본다.
  표지가 먼저 끝나면 표지 단계는 건너뛴다.
- 새로 만든 표지 두 장에서 인물과 앵글이 구별되고, 글자나 명찰이 없는지 확인한다.

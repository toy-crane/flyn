# 스토리 만들기 인터뷰의 뜻과 말투를 다시 확인한다

## 남은 문제

최신 인터뷰 프롬프트는 고정 대화 3회, 응답 60개의 기계 검사를 모두 통과했다. 하지만
출력 전문에는 다른 언어의 문자가 섞이거나 말투가 흔들린 답이 있고,
`교환이나 환불 절차를 확인한 뒤`처럼 사용자가 요청하지 않은 절차를 이미 마친
것으로 읽힐 수 있는 제안도 있다. 기계 검사 통과만으로 대화 품질을 확인할 수 없다.

## 근거

- [최종 수정 검증 기록](../../apps/api/eval/results/story-fixes-review-2026-09-13.md)의
  인터뷰 절에 60개 결과와 남은 의미 문제가 있다.
- [앞선 검증 기록](../../apps/api/eval/results/story-evaluation-review-2026-09-13.md)에는
  수정 전 기계 검사 실패와, 여러 화의 빈 부분을 한꺼번에 묻거나 결말을 미리 가정한
  사례가 있다. 최신 결과와 섞어 전체 통과로 읽지 않는다.

## 다음 확인

- 같은 입력을 여러 번 실행하고 출력 전문을 읽는다. 한 화씩 필요한 부분을 묻는지,
  이미 말한 조건을 지키는지, 결과를 미리 정하지 않는지 확인한다.
- 실제 앱에서 설명을 읽고 장면을 판단할 수 있는지, 무엇에 답하면 되는지, 한국어
  해요체가 자연스러운지 확인한다. 문장 수와 줄바꿈만으로 판정하지 않는다.
- 문제가 재현되면 [스토리 만들기](../decisions/story-creation.md)의 대화 원칙을
  유지하며 프롬프트와 평가 사례를 함께 고친다.

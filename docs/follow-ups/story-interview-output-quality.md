# 스토리 만들기 인터뷰의 뜻과 말투를 다시 확인한다

**Symptom**: 최신 인터뷰 프롬프트는 고정 대화 3회, 응답 60개의 기계 검사를 모두 통과했지만 출력에 다른 언어의 문자가 섞이거나 말투가 흔들린다. `교환이나 환불 절차를 확인한 뒤`처럼 사용자가 요청하지 않은 절차를 이미 마친 것으로 읽힐 수 있는 제안도 있다.

**Observed evidence**: [최종 수정 검증 기록](../../apps/api/eval/results/story-fixes-review-2026-09-13.md)에 60개 결과와 남은 의미 문제가 있다. [앞선 검증 기록](../../apps/api/eval/results/story-evaluation-review-2026-09-13.md)에는 여러 화의 빈 부분을 한꺼번에 묻거나 결말을 미리 가정한 사례가 있다. 앞선 기계 검사 실패를 최신 결과와 섞지 않는다.

**Suspected cause**: 모델 출력의 의미와 말투를 기계 검사가 모두 판정하지 못한다. 정확한 발생 조건은 아직 확인하지 않았다.

**What was tried**: 한 화씩 묻고 결말을 미리 정하지 않는 지침을 보강했다. 고정 대화 3회 60개 응답의 기계 검사를 통과했지만 전문 검토는 완전히 통과하지 않았다.

**Proposed next step**: 같은 입력을 여러 번 실행해 출력 전문을 읽는다. 한 화씩 필요한 부분을 묻고 이미 말한 조건을 지키는지 확인한다. 실제 앱에서 설명으로 장면을 판단할 수 있고 무엇에 답하면 되는지, 해요체가 자연스러운지도 확인한다. 문장 수와 줄바꿈만으로 판정하지 않는다. 문제가 재현되면 [스토리 만들기](../decisions/story-creation.md)의 대화 원칙을 지키며 프롬프트와 평가 사례를 함께 고친다.

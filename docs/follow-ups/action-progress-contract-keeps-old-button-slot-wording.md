# 작업 진행 표시 계약이 버튼 선행 슬롯의 옛 배치를 적고 있다

**Symptom**: 두 결정 계약이 공용 `Button` 안의 진행 표시 배치를 다르게 적는다.
[모바일 작업 진행 표시](../decisions/mobile-action-progress.md)는 컨트롤 안의
진행 표시가 "원래 아이콘 자리와 문구 위치, 컨트롤 크기를 유지"하고 아이콘과 같은
크기의 표시 영역을 쓴다고 적는다. 더 나중에 정한
[모바일 컴포넌트 선택](../decisions/mobile-component-selection.md)은 선행 슬롯이
HeroUI가 주는 줄 안 슬롯을 쓰고 절대 위치로 라벨 밖에 두지 않는다고 적는다.

**Observed evidence**: 2026-09-14 heroui-alignment task 01(커밋 259225d)에서
공용 `Button`을 줄 안 슬롯으로 바꿨다. 앞 아이콘이 없는 버튼은 진행 중일 때 진행
표시와 간격의 절반쯤 문구가 오른쪽으로 옮겨진다. 버튼 상자 크기는 그대로다. Android
에뮬레이터 화면 녹화에서 `다시 시도하기`가 이렇게 움직이는 것을 확인했고,
`mobile-ui-consistency-reviewer`도 두 계약의 문장이 어긋난다고 짚었다. 앞 아이콘
16pt를 20pt 진행 표시로 바꾸는 버튼은 2pt가 움직이지만 지금 그런 호출은 없다.

**Suspected cause**: 진행 표시 계약은 절대 위치 슬롯을 쓰던 때 쓰였고, 컴포넌트
선택 계약과 승인된 스펙이 줄 안 슬롯으로 정한 뒤 문장을 따라 고치지 않았다.

**What was tried**: 구현은 컴포넌트 선택 계약과 스펙을 따랐다. 계약 문장은 고치지
않았다. 사용자가 문구 위치 이동을 받아들였는지 확인된 기록이 없다.

**Proposed next step**: 사용자에게 진행 중에 문구가 조금 옮겨지는 것을 받아들이는지
확인한 뒤, 진행 표시 계약의 컨트롤 안 배치 문장을 줄 안 슬롯 기준으로 고치거나
문구 위치를 지키는 방법을 다시 정한다.

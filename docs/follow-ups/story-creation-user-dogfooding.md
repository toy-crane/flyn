# 사용자가 두 화짜리 스토리의 재미를 확인한다

## 남은 문제

에이전트가 두 화를 완주했고 자동 평가도 실행했지만, 실제 사용자가 원하는 상황을
경험했는지와 계속 플레이하고 싶은지는 확인하지 않았다. 구현과 기계 검사 결과를
사용자의 답으로 대신하지 않는다.

## 다음 확인

- 사용자가 원하는 상황 두 개를 플레이 전에 정하고, 화 사이에 제작 인터뷰 없이
  끝까지 플레이한다.
- 원하는 상황이 실제로 나왔는지, 상황을 알고 시작해도 다음 전개가 궁금했는지,
  앞 화의 선택이 다음 화에 영향을 줬다고 느꼈는지 묻고 답을 기록한다.
- 인터뷰가 길어서 첫 플레이를 미루게 되는지, `에피소드 추가하기`를 알아보고
  원하는 다음 상황을 떠올릴 수 있는지도 함께 살핀다.

[스토리 만들기 결정 계약](../decisions/story-creation.md)은 승인된 동작을 담는다.
이 기록은 사용자 확인이 남았다는 사실만 담는다.

# iOS 자동 입력이 긴 한국어 문장을 한 글자로 줄인다

**증상**: 스토리 만들기 입력창에 긴 한국어 문장을 `agent-device fill`로 넣으면 첫 글자 `해`만 남는다.

**관찰 근거**: 2026-09-16, `agent-device` 0.20.5, iOS `flyn-slot-1`, 세션 `prompt-ios`에서 `해외 회사 첫 팀 회의에서 경력과 맡을 일을 영어로 소개하고 싶어요. 경력직인데 영어가 서툴러서 긴장돼요.`를 입력했다. 명령은 `TEXT_ENTRY_MISMATCH`, expected 전체 문장, observed `해`를 반환했다. 로그는 `/Users/toycrane/.agent-device/sessions/prompt-ios/runner.log`에 있다. 짧은 닉네임과 영어 문장 입력은 통과했다.

**추정 원인**: iOS 한글 조합과 자동 입력 도구의 입력·확인 과정이 충돌할 가능성이 있다. 앱의 직접 입력 문제인지는 확인하지 않았다.

**시도한 방법**: 같은 뜻의 영어 문장을 입력해 전송하고 한국어 모델 응답을 확인했다. 앱 입력 코드와 기기 데이터는 바꾸지 않았다.

**다음 확인**: 같은 입력창에서 직접 한국어 입력과 설치된 도구의 한국어 `fill`을 비교한다. 도구의 최신 버전에서도 재현되는지 확인한 뒤 앱과 도구 중 원인을 좁힌다.

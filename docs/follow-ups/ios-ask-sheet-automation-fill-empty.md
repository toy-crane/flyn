# iOS 물어보기 시트의 자동 입력이 빈 값으로 끝난다

**Symptom**: `agent-device fill`로 AI에게 물어보기 시트에 글을 넣으면 `TEXT_ENTRY_MISMATCH`와 빈 입력값이 나온다.

**Observed evidence**: 2026-09-13, agent-device 0.20.5, iOS Simulator `flyn-slot-4`, 세션 `notation-final`에서 한국어 한 줄과 영어 한 줄이 모두 실패했다. 진단 ID는 `mtyjzxdx-7e73cee6`, `mtyk0o96-3989ed91`이다. 같은 세션의 에피소드 입력창에서는 영어와 한국어 한 줄 입력이 정상 작동했다.

**Suspected cause**: 시트 입력창의 포커스 또는 도구의 붙여넣기 경로가 원인일 수 있다. 실제 키보드 입력의 제품 결함인지는 확인하지 못했다.

**What was tried**: 첫 실패 뒤 화면에 남은 Paste 메뉴를 눌렀지만, 원래 클립보드에 있던 다른 문장이 들어갔다. 그 문장을 보냈고 답은 정상적으로 도착했다. 영문으로 다시 fill해도 빈 값 오류가 났다. 시트를 닫고 에피소드로 돌아가면 fill이 동작했다. 실패한 fill이 클립보드에 의도한 글을 남겼다고 가정하면 안 된다.

**Proposed next step**: 같은 시트에서 사람이 키보드로 입력하는 경우와 자동 입력을 비교한다. 자동 입력을 다시 시도할 때는 전송 전에 초안의 실제 값을 확인한다. 도구의 포커스·붙여넣기 진단을 조사하며 앱 데이터는 초기화하지 않는다.
